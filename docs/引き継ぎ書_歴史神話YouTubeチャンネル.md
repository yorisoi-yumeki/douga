# 引き継ぎ書：歴史・神話解説YouTubeチャンネル企画

作成日：2026年9月15日
このドキュメントは、Claude（チャット）側で行った企画検討の内容を、Claude Code側での作業に引き継ぐためのものです。

---

## 1. プロジェクト概要

日本神話・ギリシャ神話・日本史・世界史などの解説動画チャンネル。
既存の解説動画との差別化ポイントは、**画面の半分を人物相関図・年表エリア、もう半分を本編映像にする**構成。
登場人物が多い歴史・神話ジャンルにおいて、相関図を見ながら視聴できることに需要があるという仮説。

- 長尺動画：画面を**左右**に分割（本編／相関図）
- ショート動画：画面を**上下**に分割（本編／相関図）

---

## 2. 収益化方針

### 各プラットフォームの収益化条件（2026年時点）

| プラットフォーム | 条件 |
|---|---|
| YouTube（長尺） | 登録者1,000人 ＋ 過去12ヶ月の総再生時間4,000時間以上 |
| YouTube（ショート） | 登録者1,000人 ＋ 過去90日のショート視聴回数1,000万回以上 |
| TikTok | フォロワー1万人 ＋ 過去30日の再生数10万回以上 ＋ 1分以上の動画 ＋ 18歳以上・個人アカウント |
| Instagram | リールの直接収益化は日本非対応（招待制のみ）。企業案件・アフィリエイト中心 |

### 方針
- **収益化の主軸はYouTube**。TikTokは第二の柱候補（ただし1分以上の動画が必須で、フォロワー1万人のハードルも高い）。
- **Instagramは直接収益化を狙わず、認知拡大・流入経路として位置づけ**。

### 必要本数の試算（YouTube長尺ルート、仮定に基づく概算）
- 動画尺10分・視聴維持率40%と仮定 → 平均視聴時間4分/回
- 必要な累計視聴回数 ＝ 240,000分（4,000時間）÷ 4分 ＝ 約60,000回（12ヶ月累計）
- 週1本ペース（年52本）なら1本あたり平均1,150回、週2本ペース（年96本）なら1本あたり平均620回が目安
- 実際の数値はアルゴリズムやバズ次第で大きく変動するため、**あくまで投稿を継続する上での目安**として使う

## 3. 動画の尺

**10分を基準にスタート**（データ上、解説・教育系ジャンルは10〜20分の範囲に収束する傾向、CrashCourseなど教育系チャンネルの実例は10〜12分）。

## 4. 画面レイアウト仕様

### 長尺（16:9・左右分割）
```
[本編映像エリア]　|　[相関図エリア]
浮世絵風イラスト　|　家系図が時系列で拡張
＋ナレーション　　|
```

### ショート（9:16・上下分割）
```
┌─────────────┐
│  本編映像　　　│ 同じ素材を再編集
├─────────────┤
│  相関図エリア　│ そのカットで関係する神だけ抜粋表示
└─────────────┘
```
ショートは相関図全体を出すと文字が小さくなりすぎるため、**そのカットに関係するノードだけを抜粋**して表示する。

## 5. 相関図デザイン仕様（確定）

- **色＝カテゴリ**、**赤枠＝ハイライト**という2つの意味を分けて設計している（混同しないこと）

| 要素 | ルール |
|---|---|
| 色分け（カテゴリ） | 夫婦＝ピンク／生まれた国土・自然神＝緑／カグツチ＝琥珀 |
| 赤枠ハイライト | 本編映像でその神が映っている間だけ、相関図側のノードに赤い枠をつける |
| ステータス表記（死亡など） | 色ではなくサブタイトルの文言で表現（例：「死亡（カグツチ出産）」） |

Canvaテンプレート実装時は、**赤枠を別レイヤーにしてシーンごとにON/OFF切り替え**できるようにすると運用しやすい。

## 6. イラスト制作方針

### 原則
- 教科書掲載・有名な絵をできる限り使う。同じ絵を本編と相関図の両方で使い回し、絵柄の一貫性を持たせる。
- **他クリエイターの動画のキャラクターデザインをそのまま模倣するのは著作権侵害リスクがあるため禁止**。あくまで公有（パブリックドメイン）の原典絵を基準にする。

### イラストの入手先（パブリックドメイン優先）
| 入手先 | 特徴 |
|---|---|
| 国立国会図書館デジタルコレクション | 「インターネット公開（保護期間満了）」表示のもののみ使用可（個人送信サービス限定のものは不可） |
| ColBase（国立文化財機構統合検索） | 東京国立博物館等所蔵品、二次利用可能な画像あり |
| Wikimedia Commons | パブリックドメイン判定済み画像の検索に便利 |

### 絵がない神のイラスト作成（AI生成）
- **ツール：Midjourney**（キャラクター参照機能＝`--cref` を使い、絵柄を固定）
- 運用：既存の浮世絵風の原典画像を基準画像として読み込ませ、同じ画風で新規キャラクターを生成する
- **色調・雰囲気は5節の色分けルールに合わせる**：
  - 夫婦（イザナギ・イザナミ）→ ピンク系、温かみ・親密さ
  - 生まれた国土・自然神 → 緑系、生命力・自然
  - カグツチ → 琥珀〜赤系、炎・危うさ
- 絵柄（線・質感）は全キャラ共通、色調のみキャラごとに変える
