# チャンネルの目的

確定日：2026年9月15日
**この文書が、すべての判断の上位にあります。** 仕様・工数・収益化の決定が目的と矛盾する場合、
目的を優先してください。

---

## 1. 目的

**日本の歴史やルーツに興味を持ち、日本人としての誇りを持つ人を増やすこと。**

**収益化は二の次**です。収益はチャンネルを継続するための手段であって、目的ではありません。

この一文により、以前の決定のうち収益化を根拠にしていたものは**根拠を失いました**（4節）。

## 3. 出発点となった言葉と、その検証結果

企画の出発点は、次の言葉でした。

> 「国の成り立ちや神話を学ばない国は100年で滅びる」
> （アーノルド・トインビーの言葉として流布）

**この言葉は、出典が確認できません。** 引き継ぎ書7節の「2つ以上の出典でクロスチェック」
ルールを適用した結果です。

| 調査 | 結果 |
|---|---|
| 国立国会図書館 レファレンス協同データベース | トインビーの主要著作・新聞記事に該当文なし。**出典不明**と結論 |
| 英語圏（Wikiquote等） | 該当する言葉は見つからない |
| 類似表現の最古 | 戸松慶議『生存法則論：日本民族の世界観 第1巻（古事記篇）』1959年<br>「中等学校の卒業生にして自国の古典を知らぬ民族は例外なく滅ぶ」 |

つまり、**1959年の日本語の文章が時間とともに言い換えられ、後からトインビーの名が付いた**
と見られます。

### この事実の扱い

**企画の否定ではありません。むしろ逆です。**

目的は「興味を持つ人を増やす」ことであり、そのためには信頼が要ります。
出典不明のまま「トインビーがこう言っている」と流せば、批判者はその1点を突いて
チャンネル全体を「デマ」と片付け、**伝えたい中身まで届かなくなります**。

**厳密な出典管理は、この目的を守るための武器です。**

なお、**この言葉の来歴そのものが1本の動画になります**。
「誰もが知るこの名言、実はトインビーは言っていない。では誰が、いつ言い始めたのか」
——正直であり、かつ「なぜ日本人は神話を学ばなくなったのか」という本題に直結します。

## 6. 出典が確認できない話の扱い（確定ルール）

**方針：「と言われている」と留保したうえで使う。** ただし留保を形だけにしないため、
次の3点を必ず守ること。

```
① 画面にも出す    ナレーションだけでなく、テロップで「出典未確認」と表示する
② 断定と混ぜない  断定形のパートと同じトーンで喋らない。明確に切り替える
③ 概要欄で分ける  「確認できた出典」と「確認できていない話」を別セクションにする
```

### 未確認の3段階（同じ扱いにしないこと）

| 段階 | 内容 | 扱い |
|---|---|---|
| **A 出典不明** | 誰が言ったか確認できない（例：トインビーの言葉） | 「と言われている」＋**出典未確認のテロップ** |
| **B 事実はあるが評価が分かれる** | WGIPの影響の大きさ、GHQ焚書の範囲など | **事実部分は断定、評価部分は両論併記** |
| **C 明確に否定されている** | 調査で偽と判明しているもの | **留保付きでも使わない**。使うなら「なぜ広まったか」の題材として |

Cを留保付きで流すと、目的である「信頼」が直接損なわれます。
