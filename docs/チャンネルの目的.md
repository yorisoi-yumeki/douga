# チャンネルの目的

確定日：2026年9月15日
**この文書が、すべての判断の上位にあります。** 仕様・工数・収益化の決定が目的と矛盾する場合、
目的を優先してください。

---

## 0. チャンネル名

**「日本のなりたち」**

> 相関図を見ながら、神話から現代までを順番に。（バナーの一文）

神話も縄文も近現代も「なりたち」に含まれるため、年表順で進む方針（2節）と整合します。
**名前に目的を載せていないのは意図的です。** 「日本の誇りを取り戻す」のような名前にすると、
すでに同じ考えの人しか入ってこなくなり、「興味を持つ人を**増やす**」という目的に反するためです。
名前は入口、主張は中身で。

---

## 1. 目的

目的は2つあります。

| | 目的 |
|---|---|
| **①** | **日本の歴史やルーツに興味を持ち、日本人としての誇りを持つ人を増やすこと** |
| **②** | **自分自身の歴史の理解度を高めること** |

**収益化は二の次**です。収益はチャンネルを継続するための手段であって、目的ではありません。

### ②が重要な理由

②があると、**再生数が伸びない時期でも制作を続ける理由が残ります**。
①だけだと、数字が出ない期間に折れやすくなります。

また②があるため、**サムネイルの作りやすさや再生数の見込みで題材を落としません**。
学びたい題材は、伸びにくくても扱います（`サムネイル仕様.md` 0節）。

この一文により、以前の決定のうち収益化を根拠にしていたものは**根拠を失いました**（4節）。

**進め方：まず日本神話を完結させ、その後は年表順に進みます。**

---

## 2. 扱うテーマ

テーマは**「日本のルーツ」ひとつ**です。柱を分けず、**年表順に進みます**。

```
神話 ──→ 縄文 ──→ 古代 ──→ … ──→ 近現代
 ↑
まずここを完結させる（古事記：国産み〜神武東征の全15話）
```

| 領域 | 例 |
|---|---|
| 神話 | 古事記・日本書紀。**最初に完結させる** |
| 縄文 | 1万年以上にわたり争いが少なかったとされる時代 |
| 神道 | 信仰のかたち、神社、祭祀 |
| 言葉 | 一音一義説など、日本語そのものをめぐる話 |
| 日本史 | 各時代の出来事と人物 |
| 近現代 | GHQ占領下の検閲・国語改革／命をかけて日本を守ろうとした人たちの記録 |

**特定の題材を「柱」として固定しません。** 年表を進むなかで、その時代の題材として扱います。

## 3. ファクトチェック済みの事項（記録）

制作中に検証し、結論が出たものを記録していきます。**動画で使う前に必ずここを確認すること。**

### トインビーの言葉（出典が確認できない）

> 「国の成り立ちや神話を学ばない国は100年で滅びる」

企画を説明する際に参考として引かれた言葉ですが、**トインビーの発言としての出典は確認できません**。

| 調査 | 結果 |
|---|---|
| 国立国会図書館 レファレンス協同データベース | トインビーの主要著作・新聞記事に該当文なし。**出典不明**と結論 |
| 英語圏（Wikiquote等） | 該当する言葉は見つからない |
| 類似表現の最古 | 戸松慶議『生存法則論：日本民族の世界観 第1巻（古事記篇）』1959年<br>「中等学校の卒業生にして自国の古典を知らぬ民族は例外なく滅ぶ」 |

**実務上の扱い**：動画で「トインビーがこう言っている」と**断定しないこと**。
言葉自体を引くなら、6節のA（出典不明）として留保付きで扱う。

## 3.5 目的の達成度を、何で測るか

目的は視聴者の内面の変化なので、直接は測れません。**目的に最も近い代理指標**を置きます。

```
測りやすい ←─────────────────────→ 目的に近い

 登録者数     平均視聴時間    再生リストの     概要欄の
                             連続視聴       出典リンクのクリック
   ↑            ↑              ↑                ↑
 目的とほぼ   最後まで見た＝  1本で終わらず  自分で調べ始めた
 無関係       関心を持った    続けて見た     ＝関心が行動になった
                                              ★主指標
```

| 指標 | 位置づけ | 測る場所 |
|---|---|---|
| **概要欄の出典リンクのクリック数** | **主指標** | YouTube Studio |
| 平均視聴時間 | 補助 | YouTube Studio |
| 再生リストの連続視聴 | 補助 | YouTube Studio |
| 登録者数 | 参考程度 | YouTube Studio |

この指標には副次的な効果があります。**出典リンクを概要欄に丁寧に置く動機が生まれる**ため、
6節の出典管理ルールと噛み合います。目的の達成と信頼性の担保が、同じ作業になります。

## 3.6 ショートの位置づけ（目的の変更で役割が変わった）

収益化が主軸だった頃と、ショートの意味がまったく変わりました。

```
【収益化が目的だったとき】
  ショート ＝ 長尺への入口
    → 「ショート→長尺の流入は1〜3%」という批判が痛い
    → 流入しないショートは無駄

【日本のルーツに興味を持つ人を増やすことが目的の今】
  ショート ＝ それ自体が完成品
    → 「そんな話知らなかった」と思った時点で、目的は達成されている
    → 長尺を見なくても成立する
    → 1〜3%という批判は、ほぼ無効になる
```

したがって**ショートは減らさず、6本を維持**します。登録者はリーチの代理指標であり、
リーチは目的そのものです。

### フックの選び方

**長尺と1対1で紐づけません。** その週の長尺と無関係なショートを出して構いません。

```
✗ 長尺1本 → その回の中からフックを6本探す
             → 6本目は必然的に弱くなる

✓ 日本のルーツ全体 → 「知らなかった度」の高い順に6本選ぶ
             → 神話・縄文・神道・言葉・消された歴史と在庫が広い
             → 弱いフックを出す必要がない
```

縄文・一音一義説・消された言葉は、いずれも**「知らなかった」の密度が神話より高い**題材です。
その回の相関図を作り直す必要もなくなるため、**1本あたり50分→30分**に下がります。

## 3.7 制作ペース（#10の置き換え）

**最初の3話は本数を固定せず、実測してから4話目以降を確定します。**

| | 見積もり |
|---|---|
| 長尺1本 | 約10時間（#17で音声工数を5分→20〜40分に修正した分を反映） |
| ショート6本 | 約3時間（長尺と切り離し、テンプレ化した場合） |
| **合計** | **週 約13時間** |

ただしこの数字は未検証です。外部レビューでは「**初心者の1本目は40〜60時間、計画の3〜4倍**」
と指摘されており、その真偽が分かっていません。推測の上に推測を重ねてペースを決めるより、
3話作って実測するほうが確実です。

**神話15話の完走を最優先**とし、本数ノルマは置きません。
本数ノルマは、出典を丁寧に追う作業（＝3.5節の主指標を上げる作業）と逆方向に働きます。

## 6. 出典が確認できない話の扱い（確定ルール）

**方針：「と言われている」と留保したうえで使う。** ただし留保を形だけにしないため、
次の3点を必ず守ること。

```
① 画面にも出す    ナレーションだけでなく、テロップで「出典未確認」と表示する
② 断定と混ぜない  断定形のパートと同じトーンで喋らない。明確に切り替える
③ 概要欄で分ける  「確認できた出典」と「確認できていない話」を別セクションにする
```

### 未確認の3段階（同じ扱いにしないこと）

| 段階 | 内容 | 扱い |
|---|---|---|
| **A 出典不明** | 誰が言ったか確認できない（例：トインビーの言葉） | 「と言われている」＋**出典未確認のテロップ** |
| **B 事実はあるが評価が分かれる** | WGIPの影響の大きさ、GHQ焚書の範囲など | **事実部分は断定、評価部分は両論併記** |
| **C 明確に否定されている** | 調査で偽と判明しているもの | **留保付きでも使わない**。使うなら「なぜ広まったか」の題材として |

Cを留保付きで流すと、目的である「信頼」が直接損なわれます。
