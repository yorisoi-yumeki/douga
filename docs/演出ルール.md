# 演出ルール（視覚効果）v1

最終更新：2026年10月18日

本編エリアの絵をどう見せるかのルール。**判断の上位は `docs/チャンネルの目的.md`**、
相関図の仕様は `docs/相関図仕様書.md` が唯一の正で、本書はそれに従属する。

## 0. 原則：1つの演出に1つの意味

相関図の原則（`相関図仕様書.md` 0節「1つの見た目に2つの意味を持たせない」）を
演出にもそのまま適用する。

```
  ❌ やらないこと              ✅ やること
  ┌──────────────┐      ┌──────────────┐
  │ 毎回ちがう演出を │      │ 演出を10種に固定 │
  │ 好みで選ぶ      │      │ 意味を1つずつ割当 │
  └──────────────┘      └──────────────┘
         ↓                       ↓
   派手だが情報にならない      「寄っている＝いま重要」と
                              視聴者が学習する
                              ＝演出そのものが情報になる
```

424技法から毎回選ぶと、この学習が起きない。**少なく・固定が目的に適う。**

### 本編と相関図は同じ意味を同時に示す

意味が重なるのは問題ではなく、むしろ設計として正しい。

```
  本編エリア（左960px）        相関図エリア（右960px）
  ┌────────────┐          ┌────────────┐
  │ 彩度 −40    │  同時に   │ ノード不透明度 │
  │ 明度 −15    │ ──────→ │     50%      │
  │ 「死んだ」    │          │  「退場」      │
  └────────────┘          └────────────┘
       1つの意味を、2つの場所で同時に示している
```

禁止しているのは「1つの見た目が2つの意味を持つ」こと。上記は違反しない。

## 1. 制約：本編エリアは8:9（ほぼ正方形）

```
長尺 1920×1080
┌────────────┬────────────┐
│  本編       │  相関図     │
│  960×1080  │  960×1080  │
│  960:1080   │            │
│   = 8:9     │            │
└────────────┴────────────┘
   960 ÷ 120 = 8
  1080 ÷ 120 = 9   ← 検算済み
```

映画は横長（16:9）前提のため、**「横の広さ」で見せる技法はこの画面では効かない。**

| 効かない | 効く |
|---|---|
| Extreme Long Shot（超ロング） | Close-Up（寄り） |
| Wide Shot（ワイド） | Low Angle（見上げる） |
| Establishing Shot（状況説明） | Bird's-Eye View（俯瞰） |
| Anamorphic（アナモルフィック） | Centered Composition（中央配置） |

これが424技法を絞る最大の基準である。

### Midjourneyは必ずUpscaleしてから使う

ズーム演出を使うと、元画像の解像度が足りなくなる。

```
必要な解像度の検算
  パネル実寸            960 × 1080 px
  110%ズーム時に必要    1,056 × 1,188 px
  Midjourney素のまま    約1,024 × 1,152 px  ✗ 不足する
  Upscale 2x 後         約2,048 × 2,304 px  ✓ 約1.9倍の余裕
```

**手順：生成 → Upscale 2x → CapCutに読み込む。** 素のまま使うとズームで画質が落ちる。

## 2. 演出10種（確定）

### A. 絵の型（Midjourneyのプロンプトで指定・追加工数0）

| # | 演出 | 意味（1つだけ） | プロンプトに足す語 |
|---|---|---|---|
| A1 | 見上げる | **神・権威** | `low angle shot, volumetric light from above` |
| A2 | 寄る絵 | **感情・決断の瞬間** | `close-up portrait` |
| A3 | 俯瞰 | **国土・地理の説明** | `bird's-eye view` |

絵を作る時点で決まるため、**あとから変えられない。** 台本に書いてから生成すること。

### B. 動き（CapCutのキーフレーム）

| # | 演出 | 意味（1つだけ） | 数値 |
|---|---|---|---|
| B1 | ゆっくり寄る | **語りが核心に入る** | 拡大 100% → 108%。中心は顔 |
| B2 | ゆっくり引く | **場面の始まり・全体を見せる** | 拡大 108% → 100% |

速度は **0.8%/秒**（10秒カットで8%）。気づかれない速さにする。
気づかれると「演出を見せられている」になり、話から注意が逸れる。

### C. 空気（CapCutのエフェクト・カラーグレーディング）

| # | 演出 | 意味（1つだけ） | 数値（初期値） |
|---|---|---|---|
| C1 | 彩度を落とす | **死・追放** | 彩度 −40／明度 −15 |
| C2 | 霧 | **神話の時代・黄泉** | オーバーレイ 不透明度 30% |
| C3 | 火の粉 | **荒ぶる神・戦い** | オーバーレイ 不透明度 40% |

**C1でモノクロ（彩度 −100）にしないこと。** モノクロは一般に「回想」の記号なので、
意味が混線する。−40 に留める。

### D. つなぎ（CapCutの編集）

| # | 演出 | 意味（1つだけ） | 数値 |
|---|---|---|---|
| D1 | 断ち切る | **衝撃・結末の先出し** | トランジションなし（0フレーム）＋効果音を同フレーム |
| D2 | 溶かす | **時間が飛ぶ** | ディゾルブ 0.5秒 |

D1は1話2〜3箇所まで。多用すると衝撃が効かなくなる。

## 3. 工数

```
1話あたりの追加工数
  A（絵の型3種）     プロンプトに書くだけ          0分
  B（動き2種）       全カットに打つ
                     15〜20カット × 1分        15〜20分
  C（空気3種）       該当カットのみ
                     3〜5カット × 1分           3〜 5分
  D（つなぎ2種）     D1が2〜3箇所、D2は既定        2〜 3分
  ─────────────────────────────────
  合計                                       20〜28分／本
```

カット数15〜20は決定#9（赤枠の切り替え＝話題単位）と同じ区切りである。

```
  1カット ＝ 1話題 ＝ 赤枠1位置 ＝ 演出1つ
     ↑ すべて同じタイミングで切り替わる。別々に管理しない
```

1本40〜60時間の見積もりに対して約0.6〜1.2%。許容範囲。
**初回のみ**、霧・火の粉のオーバーレイ素材を選ぶ作業が1〜2時間かかる（7節参照）。

## 4. Midjourneyプロンプトの定型文

```
<場面の描写>, Japanese mythology, <A1/A2/A3のいずれか>, <ライティング>
  --ar 8:9 --sref <スタイル参照画像のURL>
```

| 用途 | アスペクト比 | 根拠 |
|---|---|---|
| 本編エリア | `--ar 8:9` | 960×1080（1節） |
| L0・L2・L3（全画面） | `--ar 16:9` | 1920×1080 |
| サムネイル | `--ar 16:9` | 1280×720 |

`--sref` は画風の固定に使う（決定#19）。`--cref` は顔・体型の一貫性用で画風には
効かないため**使わない**。

## 5. 台本への書き方

赤枠タイミングと同じ欄に演出も書く。欄を分けない。

```
【カット7】 0:03:20 〜 0:03:48
  赤枠：スサノオ
  演出：A1 見上げる ＋ B1 ゆっくり寄る ＋ C3 火の粉
  絵  ：スサノオが十拳剣を抜く
  語り ：「スサノオは、腰の剣を抜いた。」
```

演出は**記号（A1・B1・C3）で書く。** 文章で書くと毎回ぶれる。

## 6. 使わないと決めたもの（424技法の分類）

出典：Melies「Cinematic Techniques」 https://melies.co/cinematic-techniques
（AI動画生成スタジオ Melies の無料リファレンス。各技法のページに載っている
プロンプトは**同社の生成ツール用**で、MidjourneyやCapCutには使えない。
技法名と、それが何を伝えるかだけを参考にしている。）

| カテゴリ | 総数 | 再現できる | 主な不可の理由 |
|---|---|---|---|
| Camera Movement | 86 | 12 | 実機の移動（ドローン・ステディカム・360度オービット）は静止画で作れない |
| Framing and Shot Size | 25 | 13 | 横の広さで見せるものは8:9で効かない（1節） |
| Camera Angles | 19 | 17 | Trunk Shot・Fourth Wall は実写前提 |
| Lighting | 41 | 38 | ほぼ全部プロンプトで指定できる |
| Composition | 32 | 25 | Dirty Frame・Screen in Screen は実写前提 |
| Lenses and Optics | 17 | 14 | 画風として指定できる。物理レンズは不要 |
| Color and Film Look | 19 | 19 | 全部カラーグレーディングで可能 |
| Time and Motion | 21 | 2 | **静止画なので速度変化が作れない**（Freeze Frameのみ実質可） |
| In-Camera and Optical Effects | 57 | 14 | Morph・Datamosh・Photogrammetry は不可 |
| Editing and Transitions | 23 | 18 | 全部CapCutで可能 |
| Atmosphere and Weather | 13 | 11 | Wet-Down・Underwater は実写前提 |
| Genre Looks | 27 | 20 | 指定はできるが**画風固定（`--sref`）に反する**ので使わない |
| Viral Looks | 44 | **0** | Melies専用のプリセット名。技法ではない |
| **合計** | **424** | **203** | |

**技術的に再現できる203のうち、採用するのは10だけ。** 残り193を使わない理由は
工数ではなく0節の原則（意味の混線を避ける）である。

### とくに注意すべき2点

1. **Viral Looks 44件は全滅。** Melies で生成する前提の商品見本であり、技法ではない。
2. **Time and Motion は2件しか使えない。** スローモーション・スピードランプ・
   タイムラプスはすべて動画素材が必要。静止画では作れない。

### CapCutで使ってよいもの・いけないもの

```
  CapCut内蔵
   ├ BGM          ❌ 禁止（決定#34）
   ├ 効果音        ❌ 禁止（決定#34）
   ├ テンプレート    ❌ 禁止（決定#34）… 音楽が同梱されるため
   └ 視覚エフェクト   ✅ 使ってよい
        （フィルムグレイン・霧・火の粉など。
          音が付かないものは Content ID ＝音声の自動検出の対象外）
```

**「映画っぽい演出」を最短で足せるのはCapCutのテンプレートだが、これは使えない。**
使えるのは単体の視覚エフェクトまで。

## 7. 未検証のまま残っているもの

本書の数値は**初期値**であり、1本目で実機確認して調整する。

| 項目 | 何が未確認か |
|---|---|
| C1の彩度 −40／明度 −15 | 「死んだ」と伝わる最小値かどうか。スマホ実機で確認 |
| C2・C3の不透明度 30%／40% | 絵と相関図の両方を邪魔しないかどうか |
| B1・B2の 0.8%/秒 | 「気づかれない速さ」の上限かどうか |
| **CapCut内蔵の視覚エフェクトの商用利用** | **規約を未確認。** 使う前にCapCutの利用規約を読むこと。不可なら外部のフリー素材（ライセンス要確認）に切り替える |
| オーバーレイ素材の調達先 | CapCut内蔵で足りるか、外部素材が必要か |

`--ar 8:9` がMidjourneyで受け付けられるかも、実際に生成して確認すること。
