## 1. 検証前に知っておくこと（公式確認の結果・2026年11月13日）

| # | 分かったこと | 検証への影響 |
|---|---|---|
| ❶ | **Firefly の IP補償は個人プランに付かない**（エンタープライズ契約が対象） | Firefly を選ぶ最大の理由が消えた。ただし「学習データがライセンス済み」自体は変わらない |
| ❷ | **Firefly の比率は固定メニューのみ**（4:3／3:4／1:1／16:9／9:16）。自由入力なし | **8:9 を直接出せない。** 1:1 で出して幅を11.1%切る運用になる |
| ❸ | **Midjourney にキャラ参照 `--oref` がある**（V7）。V8.1/8.2 は Edit Model で参照画像を最大4枚 | 「Midjourney は顔を揃えられない」という前提が怪しい。**決定#19 の見直しが必要**（課題V） |
| ❹ | **`--oref` は Fast Mode と非互換**（公式）。第三者情報では「Relax のみ対応」 | **Basic $10 では使えない可能性。** Relax は Standard $30 以上 |
| ❺ | **Leonardo は 8:9 を正確に出せる**（幅・高さを8の倍数で自由指定）。`896 × 1008 px` がちょうど 8:9 | 3候補で唯一、仕様どおりの比率が出る |
| ❻ | **Firefly のキャラ一貫性機能「Elements」はベータ** | ベータ機能は IP補償の対象外とされる。❶とあわせて二重に弱い |

⚠ ❹は**第三者情報を含む推定**。課金する前に、必ずアプリ内で `--oref` が使えるか確かめること。

## 2. 手順：無料で試せるものから順に

```
  ① Leonardo.Ai   無料枠（150トークン/日）で5枚     費用 0円
         ↓ 顔が揃わなければ、ここで落とす
  ② Adobe Firefly 無料枠で5枚                      費用 0円
         ↓ 8:9 が出せないことは確定済み（❷）
  ③ Midjourney    課金が必要（無料枠なし）          費用 $10〜30
         ↓ ❹の確認を先にすること
  ④ 判定シートを埋めて決める
```

**①②を先にやる理由：0円で落とせる候補があるなら、課金の前に落とす。**
①で顔が揃えば、③に課金せず決めてもよい（決め方は5節）。

### 共通の進め方

```
  1枚目（正面）を生成する
        ↓ これを参照画像にする
  2〜5枚目を、1枚目を参照に指定して生成する
        ↓
  5枚を1画面に並べて見る ← ここが判定
```

| ツール | 参照画像の指定方法 | 比率の指定 |
|---|---|---|
| Leonardo.Ai | Character Reference に1枚目をアップロード | Custom で `896 × 1008 px` |
| Adobe Firefly | Elements（ベータ）に保存し `@` で呼ぶ／Boards にキャラシートを参照として読む | 1:1 を選び、**書き出し後に幅を 1024→910px にトリミング** |
| Midjourney | `--oref <1枚目のURL>`（V7）／V8.1・8.2 は Edit Model | プロンプト末尾に `--ar 8:9` |

⚠ **Firefly のトリミング計算**：1:1 で 1024×1024 を出し、高さ1024を保ったまま
幅を `1024 × 8 ÷ 9 = 910px` に切る。**幅の11.1%が捨てられる。**
顔が中央にないと切れるので、生成時に `centered composition` を足すこと。

### 3-3. 5枚ぶんの場面句

**組み立て方：`共通画風句` ＋ `固定句` ＋ `場面句`**（この順。カンマ区切り）

| # | 狙い | 場面句 | 注意 |
|---|---|---|---|
| 1 | **基準画像**（正面） | `front view, bust-up portrait, facing the viewer, centered composition` | ここが全ての土台 |
| 2 | 角度が変わっても同じ顔か | `side profile view, bust-up, facing left, centered composition` | 鼻と顎の線を見る |
| 3 | 顔が小さくても崩れないか | `full body, distant wide shot, standing alone on an empty shore, centered composition` | 服装も一緒に確認 |
| 4 | 表情を変えても同じ顔か（怒り） | `close-up portrait, brows drawn together, restrained anger, mouth closed, centered composition` | ⚠下の注を読む |
| 5 | 表情を変えても同じ顔か（悲しみ） | `close-up portrait, downcast eyes, restrained sorrow, mouth closed, centered composition` | ⚠下の注を読む |

> ⚠ **4・5 では、共通画風句から `calm unexaggerated expression, ` を消すこと。**
> 「表情を誇張しない」と「怒り」「悲しみ」は矛盾し、ツールがどちらを採るか分からない。
> **これは `docs/絵柄仕様.md` 1節の句と演出A2（寄る絵＝感情の瞬間）の食い違いで、
> 本検証で見つかった未解決の課題。** 検証後に共通画風句を直すか決める必要がある。

## 5. 決め方（**検証を始める前に読んで、途中で変えないこと**）

```
  ステップ1  顔の一貫性が △ か × のツールは、その場で落とす
             ↓  ここを妥協すると全246枚に響く。他がどれだけ良くても落とす

  ステップ2  残ったものの中から、次の順で選ぶ
             ① 8:9 が直接出せる
             ② 1枚あたりの所要時間が短い
             ③ 月額が安い

  ステップ3  全部が △ 以下だったら → 3候補とも不採用
             比較.md 2節の「参照画像編集系」を新たに調べ直す
```

**事前に決めておく理由**：5枚を見たあとで基準を作ると、
「せっかく課金したから」でツールを正当化してしまう。

**原則：検証画像は基準画像にしない。** 落としたツールの絵が混ざると追えなくなる。
ただし**採用したツールの1枚目（イザナギ正面）が納得できる出来なら、基準画像に昇格させてよい。**
その場合は `episodes/_anchors/01_イザナギ_基準.png` と
`01_イザナギ_基準_プロンプト.txt` として保存する（`docs/絵柄仕様.md` 4節）。
