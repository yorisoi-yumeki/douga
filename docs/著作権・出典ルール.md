# 著作権・出典表示ルール

作成日：2026年9月15日
※本書の内容は2026年9月時点で各公式サイトを確認したもの。**規約は変わるため、年1回は再確認すること。**

---

## 1. Midjourney：商用利用には有料プランが必須

| 項目 | 内容 |
|---|---|
| 商用利用の条件 | **有料プランへの加入が必須**。無料では商用利用の権利が一切ない |
| 最安プラン | Basic 月10ドル（ただし**実用にはStandard 月30ドルが必要**。下記参照） |
| 大企業の例外 | 年間売上100万ドル超の企業はPro（月60ドル）またはMega（月120ドル）が必要（個人には無関係） |
| 生成物の所有 | 有料加入者は生成物を所有できる |

**計画への影響**：収益化前から固定費が発生する。引き継ぎ書9節のツール一覧には
コストの記載がなかったため、ここに明記する。

外部レビューの指摘により、**Basicでは足りない**ことが判明した。1話に必要なカットは
30〜50枚で、当たりを出すには1カットあたり10〜20回の生成が要るため、実際に必要な
生成回数は300〜1,000ジョブ。Basic（月約200ジョブ相当）では1話分ももたない。

さらに**Canva Proも必要**（背景透過PNGの書き出しは無料版では不可）。

| ツール | プラン | 月額 | 年額 |
|---|---|---|---|
| Midjourney | Standard | 30ドル | 約54,000円 |
| Canva | Pro | 1,500円 | 18,000円 |
| **合計** | | | **約72,000円** |

**画風の固定には `--sref`（スタイル参照）を使うこと。** 引き継ぎ書6節にある `--cref` は
顔・体型などキャラクターの一貫性を保つ機能で、画風の固定には使えない。

**補足（リスク）**：米国の著作権法では、AIが生成しただけの画像は「人間の創作」にあたらず
著作権が認められない可能性がある。つまり**自分のイラストを他人に無断使用されても、
権利主張が難しい**。動画全体としては編集・構成に創作性があるため保護されるが、
イラスト単体の権利は弱いと認識しておく。

## 2. 国立国会図書館デジタルコレクション

| 項目 | 内容 |
|---|---|
| 使えるもの | 書誌情報の公開範囲が「**インターネット公開（保護期間満了）**」のものだけ |
| 使えないもの | 「図書館・個人送信限定」のものは不可 |
| 許諾 | **商用利用でも許諾は不要** |
| 注意点 | **著作者人格権は保護期間満了後も消滅しない** |

### 著作者人格権への対応（重要）

保護期間が切れても、次の3つの権利は残ります。

| 権利 | 意味 | 本企画での対応 |
|---|---|---|
| 氏名表示権 | 作者名を表示する権利 | **絵の作者名を概要欄に記載する**（例：葛飾北斎） |
| 同一性保持権 | 意に反する改変をされない権利 | **トリミング・色調整は慎重に**。切り抜いて別人の絵と合成するような改変は避ける |
| 公表権 | 未公表作品を公表する権利 | 公開済み資料のみ使うので問題なし |

**計画への影響**：引き継ぎ書6節は「同じ絵を本編と相関図の両方で使い回す」としているが、
**加工の程度に注意が必要**。原則として、切り抜きと拡大縮小にとどめ、
絵の内容を改変しない。

## 3. ColBase（国立文化財機構所蔵品統合検索システム）

| 項目 | 内容 |
|---|---|
| 許諾 | **不要**。商用・非商用を問わず無料で利用可 |
| 条件 | **出典を明記すること**（これが必須条件） |
| 表記例 | `出典：ColBase (https://colbase.nich.go.jp/)` |
| 個別作品のURL | スペースが限られる場合は省略可。ただし**ホームページURLは必ず明記** |

## 4. 本チャンネルの運用ルール（確定）

### 動画の概要欄に必ず記載する

```
─────────────────────────────
【使用素材の出典】

・画像：出典 ColBase (https://colbase.nich.go.jp/)
・画像：国立国会図書館デジタルコレクション
        「〇〇図」 作者：〇〇
・BGM：YouTubeオーディオライブラリ
・効果音：効果音ラボ
・音声合成：VOICEVOX（キャラクター名）
─────────────────────────────
```

### チェックリスト（公開前に毎回確認）

- [ ] 国会図書館の画像は「インターネット公開（保護期間満了）」表示のものか
- [ ] 原典絵の**作者名**を概要欄に書いたか（氏名表示権）
- [ ] 原典絵の加工は切り抜き・拡大縮小にとどめたか（同一性保持権）
- [ ] ColBaseの画像を使った場合、**ホームページURL**を書いたか
- [ ] BGMはYouTubeオーディオライブラリ、効果音は効果音ラボから取ったか
- [ ] VOICEVOXのクレジットを書いたか
- [ ] Midjourneyの**有料プランが有効**な状態で生成した画像か
