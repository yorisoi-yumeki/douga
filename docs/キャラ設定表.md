# キャラ設定表（全33人）

最終更新：2026年11月13日

**画風・服装の方針は `docs/絵柄仕様.md`（本書の上位）。**
本書は個々の神の見た目を固定するための表。246枚の絵はすべてここに従う。

---

## 0. この表の使い方

```
  絵を1枚つくるときの手順
  ┌──────────────────────────────────────┐
  │ ① 絵柄仕様.md 1節の「共通画風句」をコピー            │
  │ ② 本書の該当キャラの「固定句」を足す                │
  │ ③ 台本のカット指定（場面・演出記号）を足す           │
  │ ④ 基準画像を参照に指定して生成                      │
  └──────────────────────────────────────┘
```

### 各項目の意味

| 項目 | 意味 |
|---|---|
| 登場 | その神が出る話。**話をまたぐ数が多いほど一貫性が重要** |
| 系統 | 相関図の6系統。帯の色がこれに連動する（絵柄仕様.md 3節） |
| 固定句 | プロンプトに毎回そのまま入れる英語句。**書き換えない** |
| 典拠 | ◎＝古事記に記述あり（確認済み）／○＝出土品・博物館解説／—＝記述なし（創作） |
| 注意 | 話によって変わる点。見落とすと顔や装備が合わなくなる |

**「典拠 —」は創作。** 動画で「こういう姿だったと言われています」と言ってはいけない。
装いの話をするのは、典拠◎のものに限る。

## 2. 個別設定

### 01 イザナギ（いざなぎ）

- **登場**：第1話・第2話（第3話の禊の場面にも出る）
- **系統**：天上・主神／空色 `#BBD9F2`
- **年齢感・体格**：30代後半／中背・肩がやや厚い
- **髪**：黒。左右の耳の横に輪に結う（みづら）。輪は大きめ。**◎**
- **顔**：目は細すぎず、まなざしは迷わない。顎に短い髭
- **衣**：生成りの麻の筒袖。藍の袴。**空色の帯**
- **装飾**：勾玉1連を首に。腕輪はなし
- **持ち物**：天沼矛（第1話・海をかき混ぜる）／十拳剣（第1話末・第2話）／湯津爪櫛・桃の実（第2話）
- **固定句**：`man in his late thirties, black hair tied in two large loops at the sides of the head, short chin beard, undyed hemp tunic with tube sleeves, indigo trousers, pale blue sash, single strand of jade comma-beads`
- **典拠**：◎古事記・黄泉「左の御髻に刺させる湯津爪櫛の男柱一箇取り闕きて」＝みづらに櫛を刺している
- **注意**：第2話の黄泉では**彩度を落とす（演出C1）**。第3話の禊は上半身のみ

## 3. 一貫性のための横断ルール

### 骨格を似せるグループ（血筋を絵で示す）

```
  三貴子          アマテラス ─ ツクヨミ ─ スサノオ        （姉弟）
  天孫の系統      アマテラス ─ ニニギ ─ ホオリ ─ ウガヤ ─ イワレビコ
  オオクニヌシ家  オオクニヌシ ─ コトシロヌシ ─ タケミナカタ （父と息子2人）
  海神の娘        トヨタマヒメ ─ タマヨリヒメ              （姉妹）
  山の神の娘      サクヤヒメ ─ イワナガヒメ                （姉妹）
  スサノオ家      スサノオ ─ スセリビメ                    （父娘）
```

**「血筋の物語」が本シリーズの背骨なので、骨格の似せ方がそのまま内容の説明になる。**

### 見分けの手段（1人1つの決め手を持たせる）

| 手段 | 使っているキャラ |
|---|---|
| 勾玉の数 | 天津神は連ねる／地上は1つ／オオクニヌシは1→3に増える |
| 髪のほどき方 | オオモノヌシ（ほどく）／トヨタマヒメ・タマヨリヒメ（垂らす）／他は結う |
| 髪飾り | クシナダヒメ（櫛）／サクヤヒメ（花）／イワナガヒメ（石）／ウズメ（蔓） |
| 体格 | タヂカラオ（最も厚い）／オオモノヌシ・ナガスネヒコ（最も高い） |
| 挂甲 | ナガスネヒコのみ |

### 顔を描かないキャラ（意図的）

| キャラ | 理由 |
|---|---|
| カグツチ | 炎そのもの。斬られる場面の配慮 |
| 黄泉醜女 | 怖がらせすぎない。一貫性の問題も回避 |
| 八十神 | 群衆。人数と一貫性の問題を同時に回避 |
| スクナビコナ | 小さすぎる |
| 赤子のウガヤ | 描き込まない |

### 直接描かない場面（語りと一致させる）

| 場面 | 代わりの表現 |
|---|---|

## 5. 典拠つきのキャラは7人だけ

```
  ◎ 古事記に装い・姿の記述があるキャラ
  ┌────────────────────────────────────┐
  │ 05 アマテラス   みづら・御統の珠・靫・高鞆             │
  │ 07 スサノオ     八拳須（胸まで届く髭）                 │
  │ 01 イザナギ     みづら（櫛を刺している）               │
  │ 02 イザナミ     黄泉の姿（蛆・8体の雷神）              │
  │ 09 ウズメ       手次・鬘・手草（蔓植物と笹）            │
  │ 12 オロチ       八頭八尾・赤かがちの目・苔と檜・爛れた腹 │
  │ 17 スクナビコナ 蛾の皮の衣・ガガイモの実の舟            │
  │ ＋ 13 オオクニヌシ・19 タケミカヅチ・28 トヨタマヒメ    │
  │    （持ち物・場面の記述あり）                          │
  └────────────────────────────────────┘
      残り23人は創作。「こういう姿だったと言われています」と言わない
```

**この7人は、原典どおりに描くだけで競合と違う絵になる。**
とくに **12 オロチ**（記述がいちばん詳しい）と **17 スクナビコナ**（蛾の皮・実の舟）は、
一般的な神話アニメがほぼ描いていない具体性がある。
