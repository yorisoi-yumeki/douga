## 決定の根拠（後から見て分かるように）

### #6 文字サイズ（スマホ縦で読めるかの検証）

iPhoneクラス（横390pt）で1920×1080の動画を表示したときの実寸。
縮小率は 390pt ÷ 1920px ＝ **0.203**（画面のどの位置でも同じ）。

| 設計上のサイズ | スマホ縦での実寸 | 判定 |
|---|---|---|
| 28px（v2当初） | 5.7pt | ✗ 読めない |
| 48px（採用） | 9.7pt | △ ギリギリ読める |
| 56px | 11.4pt | ○ 読めるが1行2個しか入らず家系図が崩れる |

48pxは「スマホ縦で神名が読める下限」かつ「家系図の横並びを3個保てる上限」。
サブタイトル32px（6.5pt）はスマホ縦では読めないが、補足情報なので割り切る。

### #6 の訂正（外部レビューで判明した計算ミス）

当初「ノード300×150px・1行3個・横余白40px」としたが、**幅が収まらない**。

```
  300px × 3個 = 900px
   40px × 2   =  80px
  ───────────────────
  合計          980px  ＞ キャンバス960px   ← 外周の余白ゼロでもはみ出す

【修正後】
  280px × 3個 = 840px
   40px × 2   =  80px
  外周20px × 2 =  40px
  ───────────────────
  合計          960px  ✓ ぴったり
```

神名48pxは維持。280px幅に48pxの文字は5文字まで（「アマテラス」は収まる。
「アメノオシホミミ」など6文字超は2行にするか40pxへ縮小する）。

L2・L3は**440×100px**（440×4＋40×3＋20×2＝1,920px）。

### #7 L2・L3を全画面にする理由

縮小率は画面のどこでも同じなので、全画面にしても**文字は大きくならない**。
変わるのは**横に何個並ぶか**。

```
 960px幅： 1ノード240px → 48pxの文字が4文字しか入らない ✗
1920px幅： 1ノード480px → 48pxの文字が10文字入る      ✓
```

L2（20ノード・8段）とL3（20ノード・9行）は960px幅に収まらないため全画面とする。

### #9 赤枠の粒度と工数の関係

CapCutのタイムラインに画像を1枚ずつ配置する作業が効く（1枚1分想定）。

| 切り替え回数 | CapCut配置作業 | 判定 |
|---|---|---|
| 7回（パート単位） | 約7分 | 赤枠が「今映っている神」を追えず、意味が薄れる |
| 15〜20回（話題単位・採用） | 約20分 | 現実的 |
| 約120回（カット単位） | 約2時間 | 週1本ペースでは続かない |

この決定により、第1話のCanvaページ数は7ページ→**15〜20ページ**に増える。

### #12 ショートの本数（「10分あるから10本」は成り立たない）

ショートは長尺の**切り出しではなく作り直し**。画面が上下分割になり（長尺は左右分割）、
相関図も抜粋ルールで作り直し、ナレーションも結論先行で書き直すため。
流用できるのはイラスト・音声のトーン・相関図の部品のみ。

上限を決めるのは素材の長さではなく、**独立して成立するフックの数**。
第1話で数えた結果は6本（うち強いものは3本）。

| 本数 | 週の工数 | 備考 |
|---|---|---|
| 3本 | 11.5時間 | 強いフックのみ |
| 6本（採用） | 14.0時間 | フックが成立する分すべて |
| 10本 | — | 素材が足りず、弱いフックで埋めることになるため非推奨 |

1本あたりの内訳：台本書き直し10分＋相関図15分＋音声生成5分＋CapCut編集20分＝約50分
（テンプレート確立後は30分程度まで下がる見込み）

### #13 仮説検証が必要な理由

引き継ぎ書1節は「相関図を見ながら視聴できることに需要がある」を**仮説**と明記しているが、
検証計画が無かった。

- 週14時間 × 15話 ＝ 約210時間（日本神話の完走）
- 週14時間 × 52週 ＝ 約728時間（収益化に必要な年52本）

相関図はCanvaのページ作成とCapCutへの配置で長尺1本あたり約2時間、全体の約2割を占める。
したがってこの検証は「チャンネルを続けるか」ではなく、
**「最も高い差別化要素がコストに見合っているか」**の検証である。

判定後の選択肢：続行 ／ 相関図を簡略化 ／ 相関図をやめて本数・品質に振り向ける
