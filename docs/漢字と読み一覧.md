| 項目 | 内容 |

| 使った典拠 | **國學院大學 古事記学センター「古事記ビューアー」の校訂本文**（底本＝真福寺本） |

| 台本で確認済の4件 | 天照大御神・建御雷神・大国主神・天忍穂耳命（決定#56） |

> ⚠ **校訂本文と訓読文で字が違う例**：大八島国は、**校訂本文が「太八嶋國」**、
> 訓読文と注釈の見出しが「大八嶋国」でした。**原文を引くときは校訂本文を見ること。**

### 提案する書き方のルール（論点1の推奨案）

```
  ❶ 用字は校訂本文に従う          伊耶那岐命（伊邪那岐命にしない）
  ❷ 字体は新字体・通行の字体に直す  國→国 ／ 賣→売 ／ 髙→高 ／ 藝→芸 ／ 迩→邇
  ❸ 反復記号は展開する            迩〻藝 → 邇邇芸 ／ 吾勝〻速日 → 吾勝勝速日
  ❹ 修飾句を落とした通称形にする    正勝吾勝勝速日天忍穂耳命 → 天忍穂耳命（#56）
  ❺ 尊称（命・神）は本文のまま残す  建御雷神／大国主神
```

**この5つで書くと、台本で確認済みの4件すべてと一致します。**
（天照大御神・建御雷神・大国主神＝大國主神の新字体・天忍穂耳命＝正式名の通称形）

## 3. 残っている論点（決まらないと69件を起案できない）

### ★論点1：用字を校訂本文に合わせるか、一般の表記に合わせるか

```
  甲案（推奨）校訂本文の用字 ＋ 新字体化
       伊耶那岐命・大国主神・八上比売・邇邇芸命・八俣遠呂智
       典拠が1つに決まる。台本の確認済4件とも一致する
       ⚠ イザナギは、視聴者が見慣れた「伊邪那岐命」と1字違いになる

  乙案  一般に流通する表記に合わせる
       伊邪那岐命・大国主神・八上比売・邇邇芸命・八岐大蛇
       見慣れた形になる
       ⚠ 典拠が「刊本で確認」になるため、岩波文庫などの入手が必要
       ⚠ 八岐大蛇は日本書紀の表記で、古事記準拠（決定#1）から外れる

  丙案  校訂本文のまま（旧字体も出す）
       伊耶那岐命・大國主神・八上比賣・迩〻藝命
       最も忠実
       ⚠ 反復記号「〻」や旧字体は、48pxの神名の下の小さい文字では読めない
```
