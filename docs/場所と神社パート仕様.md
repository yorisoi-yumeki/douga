# 「場所と神社」パート仕様 v1

最終更新：2026年10月31日

物語の舞台が現代のどこか、その神がどこに祀られているかを、動画の最後に解説するパート。
判断の上位は `docs/チャンネルの目的.md`。出典の扱いは `docs/著作権・出典ルール.md` に従う。

---

## 0. なぜこのパートを作るのか

**目的の測り方（決定#24）に直結するから。**

```
  主指標 ＝ 概要欄の出典リンクのクリック数
            ↑
  「この神社は島根県安来市にあります」
     → 行ってみたい
     → 概要欄の神社公式サイトをクリック
     → 「自分で一次資料を見に行った人」＝興味を持った人そのもの
```

物語だけで終わると、出典リンクを踏む動機がない。**このパートが動機を作る。**

副次的に、15話ぶんの神社が溜まると「日本神話の神社マップ」という
シリーズ横断の資産になる（4節）。

## 1. 位置と尺

```
  0:00-0:30    フック
  0:30         L0 登場人物カット 1.5秒（全画面）
  0:30-8:30    本編（左右分割）
  8:30-9:10    まとめ ＋ L3 全体系譜図（全画面）
  9:10-10:20   ★ 場所と神社（全画面）← 本書の対象
  10:20-11:00  次回予告・出典案内
  ────────────────────────────
  尺 11分（決定#38で 10分 → 11分 に変更）
```

**最後に置く理由**

1. 見終わった人にしか意味がない情報（L3をまとめへ移したのと同じ理屈・#33）
2. 途中に挟むと物語が切れる
3. 「行ってみよう」で終わると、出典リンクへの導線になる

**尺は約70秒。** 1項目あたり15〜20秒 × 4項目を上限とする。

## 3. 出典の扱い（最重要）

**比定地と神社を同じ扱いにしてはいけない。** 混ぜると、チャンネルの信頼性が
いちばん壊れやすい箇所になる。

| 段階 | 対象 | 語尾 | 画面表示 |
|---|---|---|---|
| **断定してよい** | 神社の所在地・祭神 | 「〜にあります」 | そのまま |
| **留保する** | 物語の地名の比定地 | 「〜**と伝わります**」 | **「伝承地」と明示** |
| **明示する** | 後世に結びついた信仰 | 「〜**とされるようになりました**」 | 「後世の信仰」と明示 |

```
  ✅ 「須我神社は、島根県雲南市にあります」        … 事実
  ✅ 「鳥髪は、奥出雲町の船通山と伝わります」       … 比定地。留保
  ❌ 「鳥髪は、奥出雲町の船通山です」             … 断定してはいけない
```

### 諸説あるときは、古事記の本文を基準にする

本チャンネルは**古事記準拠**（決定#1）。比定地に争いがあるときは、
**古事記の原文が何と書いているかを先に示し、それに合う説を主として扱う。**
異説は「日本書紀では」「別の説では」と添える。

これは競合との差別化にもなる。**原文を基準に説を並べているチャンネルは少ない。**

## 4. 地図は国土地理院、写真は使わない

| 素材 | 判断 |
|---|---|
| ネット上の神社写真 | ❌ 著作権。出所不明の画像は使えない |
| Midjourneyで神社を生成 | ❌ **実在の神社の写真と誤認させる。** 出典ルールの精神に反する |
| 国土地理院「地理院地図」 | ✅ 出典明記で利用可（⚠ 利用規約は公開前に要確認） |
| 自分で撮影した写真 | ✅ 将来の選択肢 |

**地図と文字だけで構成する。** 絵が必要な箇所は、本編で作った既存イラストを流用する。

### ピンは足していく（シリーズの資産にする）

```
  第1話  日本地図に ● を2つ
  第2話  前回の ● を薄く残し、新しい ● を足す
  第3話  さらに足す
    ⋮
  第15話 日本全国に ● が並ぶ
         → 「日本神話の神社マップ」が完成する
```

毎回ゼロから作らない。**Canvaの1ファイルにピンを足していく。** 2話目以降の工数が下がる。

## 5. 概要欄への書き方

動画の最後で「概要欄にリンクがあります」と必ず言う。**これが主指標の入口になる。**

```
▼ この回に出てきた場所と神社
・多賀大社（滋賀県犬上郡多賀町）     https://…
・伊弉諾神宮（兵庫県淡路市多賀）      https://…
・比婆山久米神社（島根県安来市伯太町）  https://…
・おのころ島神社（兵庫県南あわじ市）    https://…
 ※比定地には諸説あります。本編で触れたとおりです。
```

リンク先は**神社の公式サイトを最優先**。公式がない場合は自治体の観光ページ。
個人ブログ・まとめサイトは使わない。

## 6. 工数

```
  調査（場所・神社の特定と出典確認）   30〜60分
  地図の作成（地理院地図＋ピン）        20分
  Canvaレイアウト（型1・型2）          20分
  ─────────────────────────
  合計                            1.2〜1.7時間／本
```

1本10時間想定に対して **12〜17%増**。小さくない。
ただし**2話目以降はCanvaの型とピン地図が使い回せる**ため、初回より下がる見込み。
