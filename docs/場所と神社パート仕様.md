# 「場所と神社」パート仕様 v2

最終更新：2026年11月14日（**型3「全国で同じ神を祀る神社」を新設し、尺を約70秒→約115秒に引き上げた**＝決定#43。
あわせて導入文を全話必須にした＝決定#42。**社数の扱いを決定#44で修正**）

物語の舞台が現代のどこか、その神がどこに祀られているかを、動画の最後に解説するパート。
判断の上位は `docs/チャンネルの目的.md`。出典の扱いは `docs/著作権・出典ルール.md` に従う。

---

## 0. なぜこのパートを作るのか

**目的の測り方（決定#24）に直結するから。**

```
  主指標 ＝ 概要欄の出典リンクのクリック数
            ↑
  「この神社は島根県安来市にあります」
     → 行ってみたい
     → 概要欄の神社公式サイトをクリック
     → 「自分で一次資料を見に行った人」＝興味を持った人そのもの
```

物語だけで終わると、出典リンクを踏む動機がない。**このパートが動機を作る。**

副次的に、15話ぶんの神社が溜まると「日本神話の神社マップ」という
シリーズ横断の資産になる（4節）。

## 1. 位置と尺

```
  0:00-0:30    フック
  0:30         L0 登場人物カット 1.5秒（全画面）
  0:30-8:30    本編（左右分割）
  8:30-9:15    まとめ ＋ L3 全体系譜図（全画面）
  9:15-11:10   ★ 場所と神社（全画面）← 本書の対象
  11:10-11:45  次回予告・出典案内
  ────────────────────────────
  尺 11分台（決定#38で10分→11分、決定#42・#43でさらに約23秒増）
```

**パートの中身は、導入1本＋4〜5カット。**

```
  導入          何を見るのかを言う（各話の内容に合わせて書く・#42）  約10秒
  型1・型2 × 4  物語の地名の比定地／ゆかりの神社                    15〜20秒ずつ
  型3 × 1       ★全国で同じ神を祀る神社（#43）                      約20秒
  ──────────────────────────────────────
  合計 約115秒
```

⚠ **v1では「約70秒・1項目15〜20秒×4項目を上限」としていた。**
決定#42（導入を全話必須）と決定#43（型3の新設）で**約115秒に引き上げた。**

**最後に置く理由**

1. 見終わった人にしか意味がない情報（L3をまとめへ移したのと同じ理屈・#33）
2. 途中に挟むと物語が切れる
3. 「行ってみよう」で終わると、出典リンクへの導線になる

**尺は約115秒。** 型1・型2は1項目あたり15〜20秒・4項目を上限、型3は約20秒で1カットとする。

**型3の3つの禁止事項**

| # | 禁止 | 理由 |
|---|---|---|
| **1** | **社数は、総本宮・総本社の公式サイトに記載がある場合だけ言う**（決定#44で修正） | 第三者サイトの数字は当てにならない。秋葉神社は「800社」「400社」と資料によって食い違い、**神社本庁などの公的な集計も見当たらない**（第1話で確認）。一方、熊野那智大社の公式には「全国5000社余の熊野神社の総本社」と明記がある。**言ってよいのは後者だけ**。言う場合は概要欄に出典URLを載せる |
| **2** | **分布の●は「代表例」と明示する**（網羅した地図に見せない） | 全社を調べていないため。網羅しているように見せると事実に反する |
| **3** | **総本宮・総本社を名乗る根拠は公式サイトで確認する** | 第三者サイトの「総本宮」表記は当てにならない。第1話では公式の「御由緒」に明記があることを確認した |

**型3で言ってよいこと**＝①その神の名（古事記の表記と、その社での表記）②総本宮・総本社の社名とふりがなと所在地 ③「全国各地にあります」という事実 ④**公式サイトに記載がある場合の社数**（#44）⑤概要欄への導線。**それ以上は足さない。**

### 題材が薄い話の扱い（決定#45）

**全15話に必ず型3を置く。** 題材が見つからない話でも省かない。

```
  第8話  根の国の試練      出る神がスサノオ（第6話）とオオクニヌシ（第7話）だけ
         → 切り口を変える：八重垣神社の縁結び → 全国の縁結びの信仰
  第14話 ウガヤフキアエズ   祀る社が鵜戸神宮（カット17）にほぼ限られる
         → 切り口を変える：神武天皇を祀る社
```

⚠ **この2話は後世に結びついた信仰を扱うため、3節の第3段階（「〜とされるようになりました」＋`後世の信仰` のラベル）を必ず使う。** 断定してはいけない。

**文字サイズは相関図と同じ規格に揃える。** 社名48px／ふりがな・所在地32px。
根拠は `相関図仕様書.md` 3節（神名48pxはスマホ縦で9.7pt相当＝読める下限）。

## 3. 出典の扱い（最重要）

**比定地と神社を同じ扱いにしてはいけない。** 混ぜると、チャンネルの信頼性が
いちばん壊れやすい箇所になる。

| 段階 | 対象 | 語尾 | 画面表示 |
|---|---|---|---|
| **断定してよい** | 神社の所在地・祭神 | 「〜にあります」 | そのまま |
| **留保する** | 物語の地名の比定地 | 「〜**と伝わります**」 | **「伝承地」と明示** |
| **明示する** | 後世に結びついた信仰 | 「〜**とされるようになりました**」 | 「後世の信仰」と明示 |

```
  ✅ 「須我神社は、島根県雲南市にあります」        … 事実
  ✅ 「鳥髪は、奥出雲町の船通山と伝わります」       … 比定地。留保
  ❌ 「鳥髪は、奥出雲町の船通山です」             … 断定してはいけない
```

### 諸説あるときは、古事記の本文を基準にする

本チャンネルは**古事記準拠**（決定#1）。比定地に争いがあるときは、
**古事記の原文が何と書いているかを先に示し、それに合う説を主として扱う。**
異説は「日本書紀では」「別の説では」と添える。

これは競合との差別化にもなる。**原文を基準に説を並べているチャンネルは少ない。**

## 4. 地図は国土地理院、写真は使わない

| 素材 | 判断 |
|---|---|
| ネット上の神社写真 | ❌ 著作権。出所不明の画像は使えない |
| Midjourneyで神社を生成 | ❌ **実在の神社の写真と誤認させる。** 出典ルールの精神に反する |
| 国土地理院「地理院地図」 | ✅ 出典明記で利用可（⚠ 利用規約は公開前に要確認） |
| 自分で撮影した写真 | ✅ 将来の選択肢 |

**地図と文字だけで構成する。** 絵が必要な箇所は、本編で作った既存イラストを流用する。

### ピンは足していく（シリーズの資産にする）

```
  第1話  日本地図に ● を2つ
  第2話  前回の ● を薄く残し、新しい ● を足す
  第3話  さらに足す
    ⋮
  第15話 日本全国に ● が並ぶ
         → 「日本神話の神社マップ」が完成する
```

毎回ゼロから作らない。**Canvaの1ファイルにピンを足していく。** 2話目以降の工数が下がる。

## 5. 概要欄への書き方

動画の最後で「概要欄にリンクがあります」と必ず言う。**これが主指標の入口になる。**

```
▼ この回に出てきた場所と神社
・多賀大社（滋賀県犬上郡多賀町）     https://…
・伊弉諾神宮（兵庫県淡路市多賀）      https://…
・比婆山久米神社（島根県安来市伯太町）  https://…
・おのころ島神社（兵庫県南あわじ市）    https://…
 ※比定地には諸説あります。本編で触れたとおりです。

▼ 全国で同じ神を祀る神社
火の神カグツチ（火之迦具土大神）を祀る秋葉神社は、全国各地にあります。
お住まいの地域の神社は、各都道府県の神社庁で探せます。
・神社本庁　（URLは公開前に確認）
```

リンク先は**神社の公式サイトを最優先**。公式がない場合は自治体の観光ページ。
個人ブログ・まとめサイトは使わない。

**型3のぶんは「▼ 全国で同じ神を祀る神社」として別に立てる。**
型1・型2（その回の舞台）と混ぜると、**ゆかりの地と全国の分社が同じ扱いに見えてしまう。**

## 6. 工数

```
  調査（場所・神社の特定と出典確認）   30〜60分
  ★型3の調査（全国に広がる神の特定・    30〜60分
    総本宮の公式確認）
  地図の作成（地理院地図＋ピン）        20分
  Canvaレイアウト（型1・型2・型3）      25分
  ─────────────────────────
  合計                            1.75〜2.4時間／本
```

1本10時間想定に対して **18〜24%増**。小さくない。
⚠ **型3の調査が増えたぶん、v1の見積もり（1.2〜1.7時間）から上がっている。**
ただし**2話目以降はCanvaの型とピン地図が使い回せる**ため、初回より下がる見込み。
