# サムネイル仕様

チャンネル：日本のなりたち
最終更新：2026年9月15日

---

## 0. なぜサムネイルを台本より先に作るのか

外部レビュー2件が独立に指摘した唯一の項目です。

```
初心者の最頻パターン
  動画を完成させる → そこからサムネを考え始める → 3時間溶かす
  → 力尽きて妥協したものを出す → 誰にも見られない
```

**ただし「サムネが作れない題材はやらない」とはしません。** 目的②（自分自身の歴史の理解度を
高める）があるため、サムネの作りやすさで題材を落とすのは本末転倒だからです。

代わりに、**サムネ作りを台本の設計作業として使います**。

```
題材を決めたら、まずサムネの文字（13文字前後）を書く
       ↓
その13文字が書けない ＝ その回で何を伝えたいかが定まっていない
       ↓
台本を書く前に、伝えたいことを1行に絞る強制力になる
```

---

## 1. 2つの型を使い分ける

| 型 | 使う場面 | 構成 |
|---|---|---|
| **A 絵主導** | 原典絵が強い題材（ヤマタノオロチ、天岩戸、因幡の白兎） | 原典絵を大きく ＋ 文字は最大9文字 |
| **B 文字主導** | 原典絵がない題材（GHQの検閲、一音一義説、縄文） | 文字が主役 ＋ 背景は無地か、暗く落とした資料画像 |

**Bがあるので、どんな題材でもサムネは作れます。**

---

## 2. A型（絵主導）

```
┌─────────────────────┐
│                     │
│   [原典絵を大きく]     │ ← 月岡芳年「日本略史 素戔嗚尊」など
│                     │    画面の大部分を使う
│  ８つの首を          │ ← 文字は最大9文字・2行以内
│  斬った男            │
└─────────────────────┘
```

**著作権上の注意**：`著作権・出典ルール.md` 2節で、原典絵の加工は
「切り抜きと拡大縮小にとどめる」と決めています（同一性保持権）。
顔だけを切り抜いて大きく使う定石は、**意に反する改変**にあたる可能性があります。

対策：**絵を切り抜かず、大きく配置する**。ヤマタノオロチ・天岩戸など原典絵が
豊富な題材では、これで十分に強いサムネになります。

---

## 3. B型（文字主導）

```
┌─────────────────────┐
│  なぜ7,000冊の本は    │ ← 問いの形にする
│  焼かれたのか         │ ← 2〜3行／1行7〜8文字
│                     │ ← 最重要語だけ色を変える（赤か黄）
│  [暗く落とした資料画像] │ ← 背景は文字の邪魔をしない濃さまで落とす
└─────────────────────┘
```

| 項目 | ルール |
|---|---|
| 行数・文字数 | 2〜3行／1行7〜8文字（合計13文字前後） |
| 文字の高さ | 画像高さの **1/6以上** |
| 文字色 | 白文字＋濃い縁取り（スマホの一覧で潰れないため） |
| 強調 | 最重要語だけ赤か黄に変える。全体を派手にしない |
| 数字 | 入れる（「1万年」「7,000冊」）と具体性が出る |
| 形式 | 「問い」にすると強い（「なぜ○○は消されたのか」） |

> **注意**：上記の数値（1/6、7〜8文字）は業界で一般的に言われている**慣習**であり、
> 実測したものではありません。最終確認は必ず、**自分のサムネをスマホの一覧サイズに
> 縮小して3秒で読めるか**で行ってください。

## 4. 相関図はサムネに使わない

チャンネルの差別化要素ですが、**サムネには使えません**。

```
一覧表示のサムネ実寸 ＝ スマホで短辺100〜140px相当
   ↓
48pxの神名を8ノード並べても、この大きさでは完全に潰れる
```

入れる場合でも「**顔2つ＋その間の線1本**」程度まで。

**これは構造的な弱点です。** 最大の差別化要素が、最大のボトルネック（クリックされるか）に
何も寄与しません。サムネは相関図とは別の勝負と割り切ってください。
