## 0. この表の使い方

**公開前に、必ずこの表の「確認状況」を見てから台本を使うこと。**

| 記号 | 意味 | 公開してよいか |
|---|---|---|
| ✅ | このセッションで検索により裏づけを取った | **原典・注釈書で再確認してから**公開 |
| ⚠ | Claudeの知識のみ。**このセッションでは未検証** | **必ず2件以上でクロスチェックしてから**公開 |
| ❌ | 誤りが判明したもの | 使わない |

```
  ⚠ が大半です。
  「調べた結果そうだった」ではなく「たぶんそうだろう」の段階です。
  ここを飛ばすと、チャンネルの信頼性がいちばん壊れやすい箇所になります。
```

**語尾の原則**（仕様書3節の再掲）

| 対象 | 語尾 |
|---|---|
| 神社の所在地・祭神 | 「〜にあります」（断定可） |
| 物語の地名の比定地 | 「〜**と伝わります**」（留保・画面に `伝承地`） |
| 後世に結びついた信仰 | 「〜**とされるようになりました**」（画面に `後世の信仰`） |

## 2. とくに注意すべき項目

### 数字を含むもの（間違えると信頼を失う）

```
  沖ノ島の出土品      8万点
  浅間神社           約1,300社
  諏訪神社           約25,000社
  熊野神社           約3,000社
  出雲大社の本殿      16丈（約48m）
  橿原神宮の創建      1890年
     ↑ すべて ⚠。公開前に一次情報で確認すること
```

**「約◯◯社の総本社」という表現は、出典によって数が違います。**
神社本庁や各社の公式サイトなど、**根拠を示せる数字だけを使うこと。**

### 二説あるもの（どちらかに決めてはいけない）

| 項目 | 説 |
|---|---|
| イザナギが鎮まった地 | 古事記＝多賀大社（近江）／日本書紀＝伊弉諾神宮（淡路） |
| イザナミの墓所 | 古事記＝比婆山／日本書紀＝花の窟 |
| 比婆山の場所 | 島根県安来市／広島県庄原市／宮内庁参考地は松江市 |
| オノゴロ島 | 沼島／絵島／おのころ島神社の丘 |
| 高千穂 | 宮崎県高千穂町／宮崎・鹿児島県境の高千穂峰 |

## 3. リンク先の方針

公式がない場合は自治体の観光ページ。
**個人ブログ・まとめサイトは使わない**（`著作権・出典ルール.md`）。
