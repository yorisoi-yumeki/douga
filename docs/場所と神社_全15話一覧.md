## 0. この表の使い方

**公開前に、必ずこの表の「確認状況」を見てから台本を使うこと。**

| 記号 | 意味 | 公開してよいか |
|---|---|---|
| ✅ | このセッションで検索により裏づけを取った | **原典・注釈書で再確認してから**公開 |
| ⚠ | Claudeの知識のみ。**このセッションでは未検証** | **必ず2件以上でクロスチェックしてから**公開 |
| ❌ | 誤りが判明したもの | 使わない |

```
  ⚠ が大半です。
  「調べた結果そうだった」ではなく「たぶんそうだろう」の段階です。
  ここを飛ばすと、チャンネルの信頼性がいちばん壊れやすい箇所になります。
```

**語尾の原則**（仕様書3節の再掲）

| 対象 | 語尾 |
|---|---|
| 神社の所在地・祭神 | 「〜にあります」（断定可） |
| 物語の地名の比定地 | 「〜**と伝わります**」（留保・画面に `伝承地`） |
| 後世に結びついた信仰 | 「〜**とされるようになりました**」（画面に `後世の信仰`） |

## 2. とくに注意すべき項目

### 数字を含むもの（間違えると信頼を失う）

```
  確認が済んだ数字（公式・公的資料）
  ┌──────────────────────────────────┐
  │ 沖ノ島の出土品    8万点が国宝        ✅ 国交省  │
  │ 浅間神社         約1,300社          ✅ 静岡県  │
  │ 諏訪神社         約1万社            ✅ 公式    │
  │ 熊野神社         4,700社以上        ✅ 公式    │
  │ 出雲大社の本殿    16丈（約48m・社伝）  ✅ 出雲市  │
  │ 橿原神宮の創建    1890年             ✅ 公式    │
  │ 戸隠神社までの距離 約760km           ✅ 自分で計算│
  │ 花の窟の巨岩      高さ約45m          ✅ 三重県  │
  │ 纒向の桃核        約2,800個          ✅ 名古屋大 │
  │ 青島の周囲        1.5km・全島が境内    ✅ 公式    │
```

### この確認で分かった、気をつけるべきこと

```
  今回の5件は、すべて「出典のすり替え」と「断定の言い過ぎ」だった
  ┌──────────────────────────────────┐
  │ 祭神を足す  → 公式に名前がなければ書かない      │
  │              鵜戸神宮に玉依姫はいなかった      │
  │ 出典名      → 「風土記」「日本書紀」を混ぜない    │
  │ 語源・由来   → 神社公式に書いていなければ留保形   │
  │ 因果の「ため」→ A と B を結ぶ根拠を一度疑う       │
  └──────────────────────────────────┘
```

**祭神は「足すほうが危ない」ことが分かりました。**
鵜戸神宮は玉依姫を祀っていると広く書かれていますが、公式は五柱と記すだけで
名前を挙げていません。**公式が名前を挙げていない祭神は、語りに入れないこと。**

**「〇〇が由来です」という語源の説明は、神社公式にある場合だけ断定できます。**
厳島神社（市寸島比売）と鹿島神宮（鹿島立ち）は、どちらも公式に記述がありませんでした。
