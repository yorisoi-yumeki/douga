# 尺の計算ルール

**この文書は「字数の数え方」と「尺の計算モデル」の唯一の正。**
2026年11月14日に、全15話の台本から規則を逆算して特定し、文書化した。
**台本の数値を直すときは、必ずこのルールで引き直すこと。**

---

## 0. なぜこの文書があるか

引き継ぎ書に「台本の字数表記が機械的な実測と全話で合わない（実測のほうが2〜57字多い）」
という課題が記録されていた。

調べた結果、**字数表記は誤っていなかった。** 数え方の規則が
どこにも書かれていなかったため、素朴に数えると合わなかっただけである。
**15話のうち13話は、下記の規則で1字も違わずに一致した。**

```
  素朴に数えた場合              規則どおり数えた場合
  ┌──────────────┐      ┌──────────────┐
  │ 第1話 4005字（+427字）│      │ 第1話 3578字（±0字）  │
  │ 第2話 3530字（+259字）│  →   │ 第2話 3271字（±0字）  │
  │ …全話でずれる        │      │ …13話が完全一致      │
  └──────────────┘      └──────────────┘
```

## 1. 字数の数え方

**対象：** 台本の `> ` で始まる行（＝語りの本文）だけ。
箇条書きの「相関図」「赤枠」「演出」「絵」や、コードブロック内の図は数えない。

**除くもの（4種）**

| # | 除くもの | 例 | 理由 |
|---|---|---|---|
| 1 | **ルビの丸括弧（中身ごと）** | `高天原（たかまがはら）` → `高天原` | 読み上げでは1回しか読まない |
| 2 | **鍵括弧「」** | `「国産み」` → `国産み` | 音にならない |
| 3 | **強調記号 `**`** | `**オノゴロ島**` → `オノゴロ島` | 書式であって文字ではない |
| 4 | **空白・改行** | — | 書式であって文字ではない |

**数えるもの**＝上記を除いた残り全部。**句読点（、。）と中点（・）は数える。**

```
  例：> 天と地が分かれたばかりの頃、高天原（たかまがはら）に、

       天と地が分かれたばかりの頃、高天原（たかまがはら）に、   ← 元の行
       天と地が分かれたばかりの頃、高天原に、                  ← ルビを除く
       ↑ ここまでで 20字（、と。を含む）
```

**⚠ 丸括弧の中身がルビでない場合（注記など）も、この規則では除かれる。**
注記を語らせたいなら、丸括弧を使わずに書くこと。

## 2. 尺の計算モデル

```
  語り秒数   = 字数 ÷ 5.5                （5.5字/秒 ＝ 330字/分）
  ＋ 1秒 × カット数                      （カット切り替えの間）
  ＋ 1.5秒                               （L0 登場人物カット）
  ＋ 5秒                                 （まとめカットの L3 を読ませる余白）
  ───────────────────────────────
  ＝ 全体の尺
```

**各カットの表示尺 ＝ そのカットの語り秒数 ＋ 1秒**
（まとめカットだけ ＋1秒＋5秒）

**時刻の表示**：累積の実数秒を四捨五入して「分:秒」で書く。
前のカットの表示終了時刻を、次のカットの表示開始時刻にする（＝表示上は必ず連続する）。
こうすると丸め誤差が累積しないので、**合計は常に「実数秒を四捨五入した値」と一致する。**

⚠ **L0 登場人物カットは1.5秒なので、表の表示上は話によって「1秒」にも「2秒」にもなる。**
実体は1.5秒。表示は四捨五入の結果にすぎない（`docs/相関図仕様書.md` 1節が正）。

### 検算例（第1話）

```
  語り 3578字 ÷ 5.5        = 650.5秒
  ＋ 1秒 × 23ブロック       =  23.0秒   ← カット22本＋「場所と神社」の導入1本
  ＋ 1.5秒（L0）            =   1.5秒
  ＋ 5秒（まとめの余白）     =   5.0秒
  ────────────────────────
  合計                      = 680.0秒 → 11:20
```

## 3. この計算値の位置づけ

⚠ **すべて計算値であり、実測値ではない。**
VOICEVOXで全文を生成して実測するまで、尺は確定しない（外部レビューK・決定#17）。

実測が出たら、**5.5字/秒という係数を実測値に差し替えて全話を引き直す。**
係数を1箇所変えれば全話が引き直せるように、この文書に係数を集めてある。

| 読み上げ速度 | 係数 | 位置づけ |
|---|---|---|
| 300字/分 | 5.0字/秒 | 遅いほうの参考値 |
| **330字/分** | **5.5字/秒** | **現在の計算に使っている値** |
| 360字/分 | 6.0字/秒 | 速いほうの参考値 |

### ⚠ 丸め方は「0.5秒は切り上げ」

**プログラムの標準的な丸め（銀行丸め）だと一致しない。**
第1話カット5の累積は192.50秒で、切り上げれば3:13、銀行丸めだと3:12になる。
**台本の既存の表はすべて切り上げで書かれている。** 引き直すときは切り上げを使うこと。

### ⚠ 課題AAの前提そのものが誤っていた（2026年11月14日に判明）

引き継ぎ書と本文書には「**導入文が第1話にしかない**」と書かれていたが、**これは誤り**だった。

```
  誤った理解                      実際
  ┌────────────────┐  ┌──────────────────────┐
  │ 第1話   … 導入あり       │  │ 第1話   … 独立した「導入」ブロックとして分離  │
  │ 第2-15話 … 導入なし      │  │ 第2-14話 … 最初の場所カットの語りの冒頭に    │
  └────────────────┘  │             導入文が埋め込まれていた          │
                              │ 第15話  … 本当に導入がない                  │
                              └──────────────────────┘
```

**第2〜14話に埋め込まれていた文（2種）**

| 型 | 文 | 字数 | 該当話 |
|---|---|---|---|
| A | ここからは、今日の物語の場所が、いまのどこにあたるかを見ていきます。 | 34字 | 2・3・5・6・7・8・9・10・11・13・14 |
| B | ここからは、今日の物語に出てきた神々が、いまどこに祀られているかを見ていきます。 | 40字 | 4・12 |

**つまり不統一だったのは「導入文の有無」ではなく「導入文を独立ブロックにしているかどうか」だった。**
第1話だけがブロックとして分け、他は語りに溶かし込んでいた。

**対応：** 決定#42（全話に導入を置き、丙案で各話の内容に合わせて書く）は変えない。
ただし作業手順を次のとおりにする。

```
  ① 最初の場所カットから、埋め込まれた導入文（A型34字／B型40字）を削除する
  ② そのカットの表の字数を 34字（または40字）減らす
  ③ 独立した「導入」ブロックとして、丙案の導入文を置く
  ④ 時刻・合計・検算・速度表・カット見出し・目次を引き直す
```

⚠ **第2話・第3話では①②を踏まずに③を行ったため、一時的に導入が二重になった。**
2026年11月14日に修正済み（第2話 10:58→10:52、第3話 11:03→10:56）。
