## 1. 結論：Midjourneyは、このチャンネルの最重要要件に弱い可能性がある

```
  このチャンネルの最重要要件
  ┌──────────────────────────────────┐
  │ 246枚の絵で、同じキャラの顔を揃えること        │
  │   スサノオ     第3・4・5・6・8話   5話またぎ   │
  │   アマテラス    第3・4・5・11・15話 5話またぎ   │
  │   オオクニヌシ  第7・8・9・10話     4話またぎ   │
  └──────────────────────────────────┘
```

複数の比較記事で、**Midjourneyのキャラクター一貫性は「△（再現度は低め）」**と評価され、
**背景重視・スタイル優先向け**と位置づけられていた。

**画風（`--sref`）は得意だが、顔を揃えるのは苦手。**
決定#19の整理と矛盾はしないが、**本チャンネルは顔を揃えることが生命線**であり、
ツール選定が要件と合っていない可能性がある。

---

## 2. 2026年時点のキャラ一貫性の主流

```
  ① シード固定         → 不十分。ポーズや背景を変えると顔が変わる
  ② 参照画像編集モデル   → 2026年の第一候補。学習不要ですぐ使える
       Qwen-Image-Edit 2511 / FLUX.1 Kontext / P-Image-Edit など
  ③ LoRA学習          → 精度は最高。ただし学習コストがかかる
```

アニメ系キャラの検証では **P-Image-Edit が安定**したという報告があった。
FLUX.1 Kontext Pro は、髪色が途中のコマで変わったとされる。

## 5. Claude Pro では賄えない（確定）

**Claudeに画像生成機能はない。** 画像を読むことはできるが、作ることはできない。

```
  Claude      → 台本・設計・調査・文章
  別サービス   → 画像生成
       ↑ この切り分けは変わらない
```

## 6. 提案：机上比較では決まらない。同じキャラを5枚作って比べる

```
  検証（所要3〜4時間・最大20ドル程度）
  ┌──────────────────────────────────┐
  │ 題材：イザナギとイザナミ（第1話の主役）         │
  │ 各サービスで、同じキャラを5枚生成する          │
  │   正面／横顔／遠景／怒り／悲しみ              │
  │ 判定：5枚並べて「同じ人物に見えるか」           │
  │ あわせて確認：                               │
  │   ・8:9 相当の比率が出せるか                  │
  │   ・商用利用の条件                           │
  │   ・セル画調・低彩度の画風が出せるか            │
  └──────────────────────────────────┘
      候補3つ：Midjourney Basic／Leonardo.Ai／Adobe Firefly
```

**この検証は、決定#35（初期投資を1つ実測して締切日を逆算する）の
「Midjourneyの絵柄固定 10〜20時間」にそのまま充てられる。**
