## 1. 結論：Midjourneyは、このチャンネルの最重要要件に弱い可能性がある

```
  このチャンネルの最重要要件
  ┌──────────────────────────────────┐
  │ 246枚の絵で、同じキャラの顔を揃えること        │
  │   スサノオ     第3・4・5・6・8話   5話またぎ   │
  │   アマテラス    第3・4・5・11・15話 5話またぎ   │
  │   オオクニヌシ  第7・8・9・10話     4話またぎ   │
  └──────────────────────────────────┘
```

複数の比較記事で、**Midjourneyのキャラクター一貫性は「△（再現度は低め）」**と評価され、
**背景重視・スタイル優先向け**と位置づけられていた。

**画風（`--sref`）は得意だが、顔を揃えるのは苦手。**
決定#19の整理と矛盾はしないが、**本チャンネルは顔を揃えることが生命線**であり、
ツール選定が要件と合っていない可能性がある。

## 2. 2026年時点のキャラ一貫性の主流

```
  ① シード固定         → 不十分。ポーズや背景を変えると顔が変わる
  ② 参照画像編集モデル   → 2026年の第一候補。学習不要ですぐ使える
       Qwen-Image-Edit 2511 / FLUX.1 Kontext / P-Image-Edit など
  ③ LoRA学習          → 精度は最高。ただし学習コストがかかる
```

アニメ系キャラの検証では **P-Image-Edit が安定**したという報告があった。
FLUX.1 Kontext Pro は、髪色が途中のコマで変わったとされる。

  │ 題材：イザナギとイザナミ（第1話の主役）         │

  │ 判定：5枚並べて「同じ人物に見えるか」           │
  │ あわせて確認：                               │
  │   ・8:9 相当の比率が出せるか                  │

## 8. 公式確認の結果（2026年11月13日）

**7節までは2026年11月1日のブログ調査。本節は公式ページで確認し直した結果。**
3節の表のうち2件を訂正した。

### 確認で崩れた前提

```
  ❶ Firefly の IP補償 → 個人プランには付かない
       「著作権リスクが最も低い」という評価の根拠が消えた

  ❷ Firefly の比率 → 固定メニューのみ。8:9 を出せない
       4:3／3:4／1:1／16:9／9:16 のみ。自由入力なし

  ❸ Midjourney にキャラ参照機能がある → --oref（Omni Reference）
       決定#19 の「--sref を使う／--cref は誤り」は情報が古い

  ❹ ただし --oref は Fast Mode と非互換
       Basic $10 では使えない可能性。Relax は Standard $30 以上
```

### ❶ Firefly の IP補償は個人プランに付かない

| 確認したこと | 結果 |
|---|---|
| Adobe公式（日本語・製品ページ） | 「安全に商用利用可能」の記載あり。**知的財産補償の記載はなし** |
| 第三者資料（複数） | IP補償は**エンタープライズ契約の対象**。個人・チームプランには含まれない |
| 補償の除外範囲 | **ベータ機能は対象外**／**他社モデル（パートナーモデル）は対象外** |

⚠ **「個人の有料プランにも付く」と書くブログもあり、情報が割れている。**
Adobeを参照している資料のほうを重く見た。**契約前にAdobeに直接確認すべき。**

**キャラ一貫性の機能「Elements」はベータ**とAdobe公式に記載（2026年11月10日更新）。
つまり**本チャンネルが使いたい機能こそが、補償の除外範囲に入る。**

### ❷ Firefly は 8:9 を出せない

公式ヘルプの比率は **Landscape 4:3／Portrait 3:4／Square 1:1／Widescreen 16:9／Vertical 9:16** のみ。
幅と高さの自由入力は見つからなかった。

```
  必要な比率 8:9 ＝ 0.889
  ┌─────────────────────────────┐
  │ 1:1  ＝ 1.000  差 0.111  ← 最も近い      │
  │ 3:4  ＝ 0.750  差 0.139                 │
  └─────────────────────────────┘
  → 1:1 で生成し、高さ1024を保って幅を 910px に切る
     1024 × 8 ÷ 9 = 910.2 → 910
     幅の 11.1% を捨てる。顔が中央にないと切れる
```

### ❸❹ Midjourney のキャラ参照

| 機能 | 記法 | 対応バージョン | 制約 |
|---|---|---|---|
| スタイル参照 | `--sref <URL>` | V7・V8系 | 画風を揃える（決定#19の内容） |
| **Omni Reference** | `--oref <URL>` | **V7のみ** | 画像1枚だけ。**GPU時間が約2倍** |
| **Edit Model** | — | **V8.1・V8.2** | 参照画像を**最大4枚** |

**Omni Reference の非互換（Midjourney公式）**：Fast Mode・Draft Mode・
Conversational Mode・`--q 4` と併用できない。
第三者情報では「`--relax` のみ対応」。

```
  Basic プラン $10/月
  ┌──────────────────────────────┐
  │ 約200ジョブ/月・Fast のみ（Relax モードなし）  │
  └──────────────────────────────┘
          ↓ --oref が Relax 必須なら
  Standard プラン $30/月（Fast 15時間 ＋ Relax 無制限）が最低ライン
          ↓
  年間 $360 ≒ 約5.6万円 ← 年間固定費7.2万円の見積もりを壊す
  （本節の円換算はすべて 1ドル155円で計算。レートは変動する）
```

⚠ **ここは第三者情報を含む推定。** 公式は「Relax のみ」と明言していない。
**課金前にアプリ内で確かめること。**

### ❺ Leonardo は 8:9 を正確に出せる

幅・高さを**8の倍数**で自由指定できる（Phoenixモデルは32〜2048）。

```
  896 × 1008 px
    896 = 8 × 112      1008 = 8 × 126   → ともに8の倍数 ✅
    896 : 1008 = 8 : 9                   → ちょうど 8:9 ✅
```

⚠ **モデルによって規則が違う。** Nano Banana 2 系は「幅と高さが個別に有効でも
対応していない組み合わせだと黙って 1:1 になる」との記載があった。**使うモデルの仕様を見ること。**
