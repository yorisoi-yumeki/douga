# 日本神話シリーズ 全話構成シミュレーション

作成日：2026年9月15日
目的：**最終話までの構造を先に確定させ、シリーズ全体で相関図の統一感を保つこと**。
第1話だけを見て仕様を決めると2話目以降で破綻することが判明したため、本書を先行して作成した。

※本書は**構造の設計図**です。個々の事実は台本執筆時に「2つ以上の出典でクロスチェック」
　ルール（引き継ぎ書7節）を改めて適用してください。系譜は**古事記準拠**とします
　（オオクニヌシの位置づけなど、日本書紀とは異説があるため。下記の注記参照）。

## 3. シミュレーションで判明した3つの問題

### 問題① 「1キャラ＝1色」は破綻する

第1話の仕様では「カグツチ＝琥珀」のように**個別キャラに色を当てて**いた。

```
第1話   色3つ（夫婦ピンク／生まれた存在 緑／カグツチ 琥珀）… 足りる
第3話   アマテラス・ツクヨミ・スサノオ                     … +3色?
第6話   ヤマタノオロチ・クシナダヒメ                       … +2色?
第10話  タケミカヅチ・コトシロヌシ・タケミナカタ           … +3色?
          ↓
最終話  約66ノード → 色を66個は作れない。10色でも視聴者は識別できない
```

**→ 色は「キャラ」ではなく「系統」に割り当てる必要がある。**

### 問題② 段数が画面の高さに収まらない

```
必要な高さ ＝ 1段あたり150px（ノード110px＋余白40px）× 16段 ＝ 2,400px
実際の高さ ＝ 1,080px
                ↓
            2倍以上のオーバー
```

**→ 「1枚の相関図を全話かけて拡張していく」という第1話の前提が成立しない。**

### 問題③ 1画面に全ノードを出しても読めない

最終話で66ノードを960px幅に詰めると、1ノードあたりの幅は100px程度になり、
神名すら読めない。相関図を見せることがチャンネルの価値なので、これは致命的。

**→ 表示を「いま必要な範囲」に絞る仕組みが必須。**

---

## 4. 解決策：相関図を4層に分ける

1枚で全部を見せようとせず、**役割の違う4種類の図**を用意する。

```
┌─────────────────────────────────────────────┐
│ L3 全体系譜図（シリーズ通し・畳んで約20ノード）        │
│    → まとめパートに表示。「今日の話は全体のここでした」  │
│    ┌───────────────────────────────┐          │
│    │ L2 章図（3〜4話単位・最大20ノード）      │          │
│    │    → 章の終わりに表示。まとまりの確認      │          │
│    │    ┌─────────────────────┐            │          │
│    │    │ L1 シーン図（最大8ノード）  │            │          │
│    │    │  → 本編中つねに表示される  │            │          │
│    │    │    メインの相関図          │            │          │
│    │    │  ┌───────────────┐    │            │          │
│    │    │  │ L0 登場人物カット │    │            │          │
│    │    │  │（最大3ノード）    │    │            │          │
│    │    │  │ → 冒頭0:30に1.5秒│    │            │          │
│    │    │  └───────────────┘    │            │          │
│    │    └─────────────────────┘            │          │
│    └───────────────────────────────┘          │
└─────────────────────────────────────────────┘
```

| 層 | 用途 | 表示タイミング | ノード数 | 段数 |
|---|---|---|---|---|
| **L0 登場人物カット** | 「今日出てくるのはこの3人」 | 冒頭0:30に1.5秒（全画面） | 最大3 | 最大2段 |
| **L1 シーン図** | 本編中つねに表示するメインの相関図 | 常時 | 最大8 | 最大4段 |
| **L2 章図** | 章のまとめ | 章の最終話の末尾 | 最大20 | 最大8段 |
| **L3 全体系譜図** | 「今日の話は全体のここでした」 | まとめパート（9:00台・全画面） | 約20（畳んだ後） | 表示9行 |

L1を最大4段に絞ることで、問題②が解消される（150px × 4段 ＝ 600px ＜ 1,080px）。

> **L3の位置は当初「各話冒頭に約3秒」でしたが、まとめへ移しました。**
> 0:20〜0:60は視聴維持率が最も急に落ちる区間で、そこに20ノードの静止図を3秒置くと
> 「読み切れない」と判断されて離脱を招くためです。代わりに冒頭には、1.5秒で読み切れる
> L0（最大3ノード）を置きます。詳細は `相関図仕様書.md` 1節。

## 5. L3（全体系譜図）を960×1080pxに収める方法

系譜上の最大深さは**16段**あり、そのまま縦に並べると1段あたり67pxしか取れず、
文字が読めない。そこで**物語上ほとんど登場しない世代をまとめノードに畳み、表示を9行に圧縮**する。

### 畳む対象（2箇所）

| 畳むもの | 実際の段数 | 畳んだ後 | 理由 |
|---|---|---|---|
| 神世七代の第1〜6代 | 段2-7（6段） | 1ノード | 本編にほぼ登場せず、名前も視聴者に馴染みがない |
| スサノオ〜オオクニヌシの中間世代 | 段10-14（5段） | 1ノード | 古事記が名前を挙げるだけで、エピソードがない |

### 圧縮後のL3（全9行）

```
行1  別天津神（5柱）
行2  神世七代 第1〜6代 ［まとめ］
行3  イザナギ ══ イザナミ
行4  アマテラス  ツクヨミ  スサノオ
行5  アメノオシホミミ      ｜ 出雲の中間6世代 ［まとめ］
行6  ニニギ                ｜ オオクニヌシ
行7  ホオリ（山幸彦）      ｜ コトシロヌシ・タケミナカタ
行8  ウガヤフキアエズ
行9  神武（イワレビコ）
```

### 寸法の確認

```
縦：1,080px ÷ 9行 ＝ 120px/行
    → ノード高さ 80px ＋ 行間 40px ＝ 120px  ✓
    → 神名は20pxで表示でき、スマホでも読める

横：1段あたり最大4ノード
    ノード幅 220px × 4 ＝ 880px ＋ ノード間余白 20px × 3 ＝ 60px ＝ 940px ＜ 960px  ✓
```

4ノードを超える行（行4は三貴子＋ヒルコ・アワシマ・カグツチ等で8個になりうる）は、
**傍系をまとめノードに畳んで4個以内**に収める。L3は現在地の把握が目的なので細部は不要。

畳んだ結果、L3のノード数は約66個から**約20個**まで減る。これで3秒の表示でも
視聴者が構造を把握できる。

## 6. 古事記準拠にあたっての注記

| 項目 | 古事記 | 日本書紀 | 本シリーズの扱い |
|---|---|---|---|
| オオクニヌシとスサノオの関係 | **六世の孫**（段15） | 子とする異説あり | 古事記に従い六世の孫。中間世代はまとめノードで表現 |
| 神世七代 | イザナギ・イザナミが第7代（段8） | ほぼ同様 | 古事記に従う |

系譜の段数は古事記準拠で確定しているため、日本書紀の異説を採用すると段数が変わる。
**シリーズを通して古事記準拠で一貫させる**こと。異説は本編ナレーションで触れるに留め、
相関図の構造は変えない。
