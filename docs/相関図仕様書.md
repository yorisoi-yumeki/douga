## 0. この仕様書で解決した矛盾

引き継ぎ書と第1話台本の間にあった食い違いを、以下のとおり確定しました。

| # | 食い違いの内容 | 確定した扱い |
|---|---|---|
| A | 死亡表現：引き継ぎ書「色で表さない」 vs 台本「グレーアウトさせる」 | **塗りはカテゴリ色のまま。退場したノードは不透明度50%に落とす。意味の説明はサブタイトル文言で行う**（下記2節・3節） |
| B | イザナミの色：引き継ぎ書「ピンク」 vs 台本「赤系」 | **ピンクに統一**（イザナミは夫婦カテゴリ） |
| C | 枠の意味：引き継ぎ書「赤枠＝映像に映っている間のハイライト」 vs 台本「カグツチが斬られたことを枠で示す」 | **枠は赤枠ハイライト専用**。斬られたことはサブタイトル文言で表す |

「色＝カテゴリ」「赤枠＝いま映っている」「不透明度＝退場したか」「文言＝詳しい状態」の
4つが、それぞれ別の意味を担当します。1つの見た目に2つの意味を持たせません。

```
  ノードの見た目 ─┬─ 塗りの色    → そのノードが何者か（カテゴリ）
                  ├─ 赤い枠      → いま本編映像に映っているか
                  ├─ 不透明度    → まだ物語に存在しているか
                  └─ サブタイトル → 状態の正確な説明（死亡・斬殺など）
```

## 2. 配色（色＝カテゴリ）

色はカテゴリだけを表します。状態（死亡など）には使いません。

| カテゴリ | 対象 | 塗り | 枠線 | 文字 |
|---|---|---|---|---|
| 夫婦 | イザナギ、イザナミ | `#F7C6D9`（ピンク） | `#D4739B` | `#4A1F35` |
| 生まれた存在（国土・自然神） | 大八島国、帰り道の6島、自然の神々、ヒルコ、アワシマ | `#C6E3C0`（緑） | `#6BA85F` | `#23401E` |
| カグツチ | カグツチ | `#F6D28A`（琥珀） | `#D08B1F` | `#4A3208` |

補足：ヒルコ・アワシマは国土でも自然神でもありませんが、**イザナギ・イザナミから生まれた存在**
として緑に含めます。新たな第4の色を増やさないための判断です。「正式な子に数えられない」ことは
不透明度50%とサブタイトル文言で表します。

背景：`#FAF6EF`（和紙色）、エリア外枠 `#D8CFC0`。浮世絵風イラストと馴染む色を選定。

## 3. 状態表現

| 状態 | 見た目 | 文言（サブタイトル） |
|---|---|---|
| 通常 | 不透明度100% | 役割など（例：「火の神」） |
| 退場（死亡・流された等） | **不透明度50%**（塗りの色は変えない） | 例：「死亡（カグツチ出産）」「正式な子に数えられず」 |
| 本編映像に映っている間 | **赤枠** `#E03131` / 太さ6px | 変化なし |

赤枠はノードの外周より2px外側に置いた角丸長方形とし、**別レイヤー（別グループ）**にして
シーンごとにON/OFF切り替えできるようにします。

## 7. ショート（9:16）の抜粋ルール

相関図全体を9:16の下半分に入れると文字が小さすぎるため、抜粋して表示します。

- **そのカットに登場する神＋直接つながる親または配偶者のみ**を表示する
- **1画面あたり最大4ノード**まで
- ノードサイズは長尺と同じ280×110pxのまま使う（縮小しない）

例：カグツチ誕生のカット → イザナギ・イザナミ・カグツチ の3ノードのみ
