# 相関図デザイン仕様書 v2（シリーズ全体確定版）

最終更新：2026年9月15日
適用範囲：**チャンネル全体**（日本神話・ギリシャ神話・日本史・世界史すべて）

この文書が相関図デザインの**唯一の正**です。引き継ぎ書5節および各話台本の画面メモと
食い違う場合は、本書を優先します。

> **v1からの改訂理由**：v1は第1話のみを対象にしていたため、シリーズ全体では破綻することが
> `docs/シリーズ構成シミュレーション.md` で判明した（色が足りない／段数が画面に収まらない）。
> 最終話（第15話 神武東征）までシミュレーションしたうえで全面的に作り直したのが本書。

## 0. 見た目の4つの役割（v1から継続・変更なし）

1つの見た目に2つの意味を持たせません。この役割分担はシリーズ全体で不変です。

```
  ノードの見た目 ─┬─ 塗りの色    → どの系統に属するか
                  ├─ 赤い枠      → いま注目している対象か
                  ├─ 不透明度    → まだ物語に存在しているか
                  └─ サブタイトル → 状態の正確な説明（死亡・斬殺など）
```

| 要素 | 意味 | 具体 |
|---|---|---|
| 塗りの色 | 系統（2節） | 5系統の固定色 |
| 赤枠 `#E03131` / 6px | いま注目している対象 | L1では「本編映像に映っているカット中」、L3では「今回の話の範囲」 |
| 不透明度50% | 退場（死亡・追放・流された等） | 塗りの色は変えない |
| サブタイトル | 状態の正確な説明 | 「死亡（カグツチ出産）」「正式な子に数えられず」 |

## 1. 相関図は3層構造（シリーズ全体の骨格）

66ノード・16段を1枚に収めることは不可能なため、役割の違う3種類の図を使い分けます。

| 層 | 名称 | 用途 | 表示タイミング | ノード数 | 段数 |
|---|---|---|---|---|---|
| **L1** | シーン図 | 本編中つねに表示するメインの相関図 | 常時 | 最大8 | 最大4段 |
| **L2** | 章図 | 章（3〜4話）のまとめ | 章の最終話の末尾 | 最大20 | 最大8段 |
| **L3** | 全体系譜図 | 「今どこの話か」の現在地マップ | 各話冒頭 約3秒 | 約20（畳んだ後） | 表示9行 |

詳細と段数の計算根拠は `docs/シリーズ構成シミュレーション.md` 4〜5節を参照。

## 2. 配色（色＝系統／チャンネル全体共通）

色は**系統**だけを表します。個別キャラに色を割り当てることは禁止です
（v1の「カグツチ＝琥珀」は、最終話で色が足りなくなるため**廃止**）。

| 系統 | 日本神話 | ギリシャ神話 | 日本史・世界史 | 塗り | 枠線 | 文字 |
|---|---|---|---|---|---|---|
| 天上・主神 | 天津神（イザナギ、アマテラス、ニニギ） | オリュンポスの神々 | 中央権力 | `#BBD9F2` 空 | `#4A87C4` | `#14304F` |

| 人間・王統 | 神武以降の天皇、人 | ヘラクレス等の英雄 | 歴史上の人物 | `#F2D98D` 金 | `#C9A227` | `#4A3708` |
| 怪異・敵対 | ヤマタノオロチ、黄泉醜女、ナガスネヒコ | 怪物（メドゥーサ等） | 敵対勢力 | `#D4C2E8` 紫 | `#8E6BBF` | `#33204F` |

### v1から廃止したルール（重要）

| v1のルール | 廃止理由 | v2での扱い |
|---|---|---|
| 夫婦＝ピンク | 「夫婦」は**関係**であって系統ではない。色は系統専用にする | 夫婦関係は**二重線**（4節）で表す。色は各人の系統に従う |
| カグツチ＝琥珀 | 1キャラ1色では最終話で色が足りない | カグツチは火の神なので**自然・国土・事物（緑）**。彼の重要性は赤枠とサブタイトルで表す |

| 関係 | 線 |

```
             │

   ┌─────────┼─────────┐

```

## 6. ショート（9:16）の抜粋ルール

- **そのカットに登場する対象＋直接つながる親または配偶者のみ**を表示する
- **1画面あたり最大4ノード**（L1の最大8よりさらに絞る）
- ノードサイズはL1と同じ280×110pxのまま使う（縮小しない）
- L2・L3はショートでは使わない

例：カグツチ誕生のカット → イザナギ・イザナミ・カグツチ の3ノードのみ

## 7. Canvaファイルの構成（全話共通の作り方）

話ごとに毎回ゼロから作らず、**共通パーツを複製して使い回す**ことで統一感を担保します。

```
Canva
├── 【共通】相関図パーツ集          … 1ファイル。全話でここから複製する
│     ・5系統 × 2サイズ のノード
│     ・赤枠ハイライト（別レイヤー）
│     ・夫婦線・親子線
│     ・背景枠（960×1080 / 1080×960）
│
├── 【共通】L3 全体系譜図           … 1ファイル・15ページ
│     ・9行の系譜図は全ページ同じ
│     ・ページごとに赤枠の位置だけ変える（＝各話の現在地）
│
└── 【話別】第N話 L1シーン図        … 話ごとに1ファイル
      ・台本のパート区切りに合わせてページを作る
      ・第1話は7ページ（8節）
```

赤枠は**必ず別レイヤー（別グループ）**にして、シーンごとにON/OFF切り替えできるようにします。
