この文書が相関図デザインの**唯一の正**です。引き継ぎ書5節および各話台本の画面メモと
食い違う場合は、本書を優先します。

## 0. 見た目の4つの役割（v1から継続・変更なし）

1つの見た目に2つの意味を持たせません。この役割分担はシリーズ全体で不変です。

```
  ノードの見た目 ─┬─ 塗りの色    → どの系統に属するか
                  ├─ 赤い枠      → いま注目している対象か
                  ├─ 不透明度    → まだ物語に存在しているか
                  └─ サブタイトル → 状態の正確な説明（死亡・斬殺など）
```

| 要素 | 意味 | 具体 |
|---|---|---|
| 塗りの色 | 系統（2節） | 6系統の固定色 |
| 赤枠 `#E03131` / 6px | いま注目している対象 | L1では「本編映像に映っているカット中」、L0・L3では「今回の話の範囲」 |
| 不透明度50% | 退場（死亡・追放・流された等） | 塗りの色は変えない |
| サブタイトル | 状態の正確な説明 | 「死亡（カグツチ出産）」「正式な子に数えられず」 |

## 1. 相関図は4層構造（シリーズ全体の骨格）

66ノード・16段を1枚に収めることは不可能なため、役割の違う4種類の図を使い分けます。

| 層 | 名称 | 用途 | 表示タイミング | ノード数 | 段数 |
|---|---|---|---|---|---|
| **L0** | 登場人物カット | 「今日出てくるのはこの3人」 | **冒頭 0:30 に 1.5秒**（全画面） | **最大3** | 最大2段 |
| **L1** | シーン図 | 本編中つねに表示するメインの相関図 | 常時 | 最大8 | 最大4段 |
| **L2** | 章図 | 章（3〜4話）のまとめ | 章の最終話の末尾 | 最大20 | 最大8段 |
| **L3** | 全体系譜図 | 「今日の話は全体のここでした」 | **まとめパート（9:00台）**（全画面） | 約20（畳んだ後） | 表示9行 |

詳細と段数の計算根拠は `docs/シリーズ構成シミュレーション.md` 4〜5節を参照。

### L3を冒頭からまとめへ移した理由

v2当初はL3を「各話冒頭に約3秒」としていましたが、**0:20〜0:60は視聴維持率が最も
急に落ちる区間**です。そこに約20ノードの静止図を3秒置くと、視聴者は「3秒では読み切れない
情報量」を前に理解を諦め、離脱の引き金になります。

また「今日の話は全体のどこか」は、**見終わった人にしか意味がありません**。
まとめパートに置くほうが、内容としても自然です。

### L0（登場人物カット）を新設した理由

L3をまとめへ移すと、視聴中に「今どこの話か」が分からなくなります。
そこで**冒頭には、読み切れる情報量だけを置きます**。

| 項目 | L0の仕様 |
|---|---|
| 表示 | 全画面 1920×1080（本編を一時的に止める） |
| 長さ | **1.5秒** |
| ノード数 | **最大3**（今回の主役と、その直接の関係者のみ） |
| ノード規格 | L2・L3と同じ **440 × 100 px**／神名48px |
| 挿入位置 | 0:30（フックの直後） |

3ノードなら1.5秒で読み切れます。L3（約20ノード）を3秒で読ませようとしたのが
そもそも無理でした。

## 2. 配色（色＝系統／全時代共通・6系統）

色は**系統**だけを表します。個別キャラに色を割り当てることは禁止です
（v1の「カグツチ＝琥珀」は、最終話で色が足りなくなるため**廃止**）。

年表順に近現代まで進むため、**神話だけでなく全時代で使える6系統**とします。

| 系統 | 神話での例 | 日本史・近現代での例 | 塗り | 枠線 | 文字 |
|---|---|---|---|---|---|
| 天上・主神 | 天津神（イザナギ、アマテラス、ニニギ） | 朝廷・中央権力 | `#BBD9F2` 空 | `#4A87C4` | `#14304F` |
| 地上・土着 | 国津神（オオクニヌシ、出雲の神々） | 地方勢力・豪族 | `#E0C9A6` 土 | `#A8813F` | `#46330F` |
| 人間・王統 | 神武以降の天皇 | 実在の人物 | `#F2D98D` 金 | `#C9A227` | `#4A3708` |
| **怪異** | ヤマタノオロチ、黄泉醜女 | — （**神話の存在にのみ使う**） | `#D4C2E8` 紫 | `#8E6BBF` | `#33204F` |
| **敵対** | ナガスネヒコ | 対立した国家・組織・人物 | `#DCB0A8` 赤褐 | `#A85A4A` | `#4A201A` |
| 自然・国土・事物 | 大八島国、自然の神々、カグツチ、草薙剣 | 地名、法令、指令、事物 | `#C6E3C0` 緑 | `#6BA85F` | `#23401E` |

背景：`#FAF6EF`（和紙色）、エリア外枠 `#D8CFC0`。

### 「怪異」と「敵対」を分ける理由

v2当初は「怪異・敵対」を紫1色にしていました。しかし年表順に近現代まで進むと、
**ヤマタノオロチ（神話の怪物）とGHQ（実在の組織）が同じ色になります**。
これは大原則「1つの見た目に2つの意味を持たせない」（0節）に反するため、分離しました。

```
【v2当初】                     【現在】
 紫 ─┬─ ヤマタノオロチ          紫   → 神話の怪物のみ
     └─ GHQ          ← 同色     赤褐 → 実在の対立勢力
```

### 敵対色を適用する基準（全話で一貫させること）

回ごとに判断がブレると「なぜこの人は敵対色で、この人は違うのか」が分からなくなります。
次の3条件で運用します。

```
① その回の主題において、日本と軍事的・政治的に対立した「側」であること
② 個人に適用するのは、その対立の意思決定者である場合に限る
   （一般の兵士・市民には適用しない）
③ 同じ人物・組織は、どの回でも同じ色にする（回ごとに変えない）
```

> **実装時に要確認**：赤褐色 `#DCB0A8` の塗りに、赤枠ハイライト `#E03131` が
> 重なったときに見分けがつくか、**スマホの実機で確認すること**。
> 塗りと枠線なので原理的には区別できますが、小さい表示では未検証です。

### v1から廃止したルール（重要）

| v1のルール | 廃止理由 | v2での扱い |
|---|---|---|
| 夫婦＝ピンク | 「夫婦」は**関係**であって系統ではない。色は系統専用にする | 夫婦関係は**二重線**（4節）で表す。色は各人の系統に従う |
| カグツチ＝琥珀 | 1キャラ1色では最終話で色が足りない | カグツチは火の神なので**自然・国土・事物（緑）**。彼の重要性は赤枠とサブタイトルで表す |

## 3. ノードの規格

| 項目 | L1（シーン図） | L2（章図）・L3（全体系譜図） |
|---|---|---|
| 形 | 角丸長方形（角丸半径16px） | 角丸長方形（角丸半径12px） |
| サイズ | **280 × 150 px** | **440 × 100 px** |
| 神名 | Noto Sans JP Bold / **48px** | Noto Sans JP Bold / 48px |
| サブタイトル | Noto Sans JP Regular / **32px** | L2のみ28px／L3はなし |
| ノード間の余白 | 縦40px・**横40px** | 縦20px・横40px |
| 外周の余白 | **左右20px** | 左右20px |
| 1行あたりの上限 | **3ノード** | 4ノード |

### 幅の検算（必ず守ること）

```
L1（キャンバス960px）
  ノード 280px × 3個      = 840px
  ノード間 40px × 2       =  80px
  外周    20px × 2        =  40px
  ───────────────────────────────
  合計                    = 960px  ✓ ぴったり収まる

L2・L3（全画面1920px）
  ノード 440px × 4個      = 1,760px
  ノード間 40px × 3       =   120px
  外周    20px × 2        =    40px
  ───────────────────────────────
  合計                    = 1,920px  ✓ ぴったり収まる
  （440px幅に48pxの文字は9文字まで。「ウガヤフキアエズ」8文字が収まる）
```

> **修正履歴**：当初この節は「280×110px／神名28px」、決定#6は「300×150px／1行3個」でした。
> 外部レビューの指摘により検算したところ、**300×3＋余白40×2＝980px ＞ 960px** で
> 物理的に収まらないことが判明。ノード幅を280pxに修正しました。
> 神名48pxは維持（スマホ縦で9.7pt相当。根拠は `決定ログ.md` #6）。

## 5. キャンバスサイズ

| 用途 | サイズ | 根拠 |
|---|---|---|
| 長尺（16:9）の相関図エリア | **960 × 1080 px** | 動画1920×1080pxの右半分 |
| ショート（9:16）の相関図エリア | **840 × 345 px** | UIに覆われない領域の実測値（下記） |

### ショートは単純な上下半分ではない（重要）

ショートの画面は、**プラットフォームのUIが上下と右側を覆います**。
1080×1920のうち、実際に使えるのは **840 × 1095 px** だけです。

| 覆われる場所 | 幅 | 何が乗るか |
|---|---|---|
| 上部 | 210px | 検索・カメラなどの領域 |
| 下部 | **615px** | タイトル・チャンネル名・登録ボタン・音源情報 |
| 右側 | 240px | 高評価・コメント・共有ボタン |

これはYouTube・Instagram・TikTokの**3媒体すべてのUIを避けた共通の安全領域**です。
TikTokにも転用する方針（#12）のため、この最も厳しい基準を採用します。

```
長尺 1920×1080                    ショート 1080×1920
┌───────────┬───────────┐          ┌─────────────┐ y=0
│           │           │          │░░░ UI 210px ░░░│
│  本編映像  │  相関図    │          ├──────────┬──┤ y=210
│  960×1080 │（L1/L2/L3）│          │  本編映像  │  │
│           │  960×1080 │          │  840×750  │UI│ ← 右240px
│           │           │          ├──────────┤  │ y=960
└───────────┴───────────┘          │ 相関図     │  │
                                   │ 840×345   │  │
   本編 : 相関図 ＝ 5 : 5           ├──────────┴──┤ y=1305
                                   │░░░ UI 615px ░░░│
                                   └─────────────┘ y=1920

                                      本編 : 相関図 ＝ 約 7 : 3
                                      y=1305より下には何も置かない
```

> **v2当初は「相関図は下半分＝1080×960」としていました。** 実測の結果、
> そのうち下615pxはUIに完全に隠れ、実際に見えるのは **840×345px（想定の約28%）**
> であることが判明したため修正しました。単純な上下半分にすると、
> **相関図の下6割が見えません**。

## 6. ショート（9:16）の抜粋ルール

- **そのカットに登場する対象＋直接つながる親または配偶者のみ**を表示する
- **1画面あたり最大4ノード**（2列 × 2行）
- ノードサイズは**L1と同じ280×150px**のまま使う（縮小しない）
- **行間だけ40px→20pxに詰める**（下記の検算参照）
- L2・L3はショートでは使わない

例：カグツチ誕生のカット → イザナギ・イザナミ・カグツチ の3ノードのみ

### 4ノードが収まることの検算

```
相関図エリア 840 × 345 px に対して

  横： 280px × 2列 ＋ 余白40px ＝ 600px ≦ 840px  ✓（余裕240px）
  縦： 150px × 2行 ＋ 行間20px ＝ 320px ≦ 345px  ✓（余裕 25px）

  ※行間を40pxにすると340pxとなり余裕が5pxしかないため、20pxとする
```

エリアが狭まっても**ノードを縮小しないこと**。縮小するとスマホで文字が読めなくなり、
3節で48pxに決めた根拠が崩れます。**収まらない場合はノードを減らします。**

## 7. Canvaファイルの構成（全話共通の作り方）

話ごとに毎回ゼロから作らず、**共通パーツを複製して使い回す**ことで統一感を担保します。

```
Canva
├── 【共通】相関図パーツ集          … 1ファイル。全話でここから複製する
│     ・6系統 × 2サイズ のノード
│     ・赤枠ハイライト（別レイヤー）
│     ・夫婦線・親子線
│     ・背景枠（長尺 960×1080 / ショート 840×345）
│
├── 【共通】L3 全体系譜図           … 1ファイル・15ページ
│     ・9行の系譜図は全ページ同じ
│     ・ページごとに赤枠の位置だけ変える（＝各話の現在地）
│
└── 【話別】第N話 L1シーン図        … 話ごとに1ファイル
      ・台本のパート区切りに合わせてページを作る
      ・第1話は7ページ（8節）
```

赤枠は**必ず別レイヤー（別グループ）**にして、シーンごとにON/OFF切り替えできるようにします。

## 8. イラストの色調とノードの色は切り離す

**ノードの色＝系統**、**イラストの色調＝その場面の性質**。別物として扱います。

```
   ノードの色  ─→ 系統を示す記号。視聴者が構造を読み取るための情報
   イラスト色調 ─→ 場面の空気。視聴者が感情移入するための演出
                     ↑ 目的が違うので、揃える必要はない
```

| 対象 | ノードの色（系統） | イラストの色調（場面の性質） |
|---|---|---|
| イザナギ・イザナミ | 空色（天上・主神） | 温かみ・親密さ |
| カグツチ | 緑（自然・国土） | 琥珀〜赤、炎・危うさ |
| ヤマタノオロチ | 紫（怪異） | 暗色・威圧感 |

Midjourneyのプロンプトは**場面の性質**に従って書いてください。ノードの色に
引きずられる必要はありません。引き継ぎ書6節にある「5節の色分けルールに合わせる」
という指示は、v1の「1キャラ1色」を前提としたものなので**廃止**です。

絵柄（線・質感）が全キャラ共通であることは変わりません（**`--sref`**で固定）。
`--cref` はキャラクターの顔・体型の一貫性を保つ機能で、画風の固定には使えません。
