## 0. 見た目の役割（1つの見た目に1つの意味）

1つの見た目に2つの意味を持たせません。この役割分担はシリーズ全体で不変です。

```
  ノードの見た目 ─┬─ 塗りの色    → どの系統に属するか
                  ├─ 墨の枠      → いま注目している対象か
                  ├─ 塗りを抜く  → この場面の中で退場したか（輪郭だけにする）
                  ├─ サブタイトル → 状態の正確な説明（死亡・斬殺など）
                  └─ 漢字        → 神名の表記（読ませるためではなく、添えるだけ）

  図の見た目   ──┬─ 帯          → 同じ世代
                  └─ 図を入れ替える → 役目が終わった（＝消す）
```

| 要素 | 意味 | 具体 |
|---|---|---|
| 塗りの色 | 系統（2節） | 6系統の固定色 |
| 強調枠 `#231815` / 8px | いま注目している対象 | L1では「本編映像に映っているカット中」、紹介カット・L3では「今回の話の範囲」（#61で赤から墨に変更） |
| **塗りを抜いて輪郭だけにする** | **その場面の中で起きた退場**（死亡・追放・退けられた等） | 輪郭と文字は系統の中間色。色相は変えない |
| サブタイトル | 状態の正確な説明 | 「死亡（カグツチ出産）」「正式な子に数えられず」 |
| 漢字（小さい文字） | 神名の表記（#51） | スマホでは読めない前提。読ませるのは紹介カットの役目 |
| 帯 `#D6C39C` | 同じ世代（#52） | ラベルは「主役から見た関係」（#53） |

### 「消す」と「輪郭だけ」の使い分け（#49・#57）

**この2つは別の意味なので、混ぜないこと。**

```
  輪郭だけ  ＝ いま見せている場面の中で、退場が起きた
               例）カット13でイザナミが死ぬ
                   → イザナミの塗りを抜いて輪郭だけにし「死亡（カグツチ出産）」と書く
                   （ここで消すと、死んだこと自体が画面から伝わらない）

  消す      ＝ 次の場面に進むとき、その場面に要らないノードを外す
               例）カット12でカグツチが生まれる図には、
                   ヒルコ・アワシマ・大八島国はもう出さない
```

**輪郭だけのまま次の場面へ持ち越すのは、その退場がまだ話の中心にある場合だけです。**
中心から外れたら消します。

## 1. 相関図は4層構造（シリーズ全体の骨格）

79ノード・16段を1枚に収めることは不可能なため、役割の違う4種類の図を使い分けます。

| 層 | 名称 | 用途 | 表示タイミング | ノード数 |
|---|---|---|---|---|
| **L0** | **登場人物紹介カット** | 「今日の物語に登場する神々」 | **冒頭 0:30 に 約15秒**（全画面） | **10前後**（横4個・最大3段） |
| **L1** | シーン図 | 本編中つねに表示するメインの相関図 | 常時（**画面の右半分**） | **上限なし。同時最大6個・平均3.9個** |
| **L2** | 章図 | 章（3〜4話）のまとめ | 章の最終話の末尾（全画面） | 最大20 |
| **L3** | 全体系譜図 | 「今日の話は全体のここでした」 | **まとめパート（9:00台）**（全画面） | 約20（畳んだ後）・表示9行 |

> ⚠ **全15話のノードの実測は `docs/L1ノード一覧.md`（2026年11月15日）を参照。**
> 累計ノード数は**66ではなく79**です（`docs/シリーズ構成シミュレーション.md` 2節の66は
> 企画段階の見積もりで、台本と合っていません。L3の設計は79件の台帳から始めること）。

### L3を冒頭からまとめへ移した理由（v2から継続）

v2当初はL3を「各話冒頭に約3秒」としていましたが、**0:20〜0:60は視聴維持率が最も
急に落ちる区間**です。そこに約20ノードの静止図を3秒置くと、視聴者は「3秒では読み切れない
情報量」を前に理解を諦め、離脱の引き金になります。

また「今日の話は全体のどこか」は、**見終わった人にしか意味がありません**。

### L0は「登場人物紹介カット」に作り替えた（#54）

v2のL0は「最大3ノード・1.5秒」でした。これを**約15秒の紹介カット**に差し替えます。

| 項目 | 旧L0（v2） | 登場人物紹介カット（v3） |
|---|---|---|
| 表示 | 全画面 1920×1080 | 全画面 1920×1080（変更なし） |
| 長さ | 1.5秒 | **約15秒** |
| ノード数 | 最大3 | **10前後**（横4個・帯で世代に分ける） |
| ノード規格 | 440 × 100 px | **440 × 180 px**／神名48px・漢字32px |
| 見せ方 | 静止画を1.5秒 | **語りに合わせて1柱ずつ現れる** |
| 文字 | なし | タイトル「今日の物語に登場する神々」＋副題「色は、その神の立ち位置を表しています」 |
| 色の凡例 | なし | **その話で実際に使う色だけ**（第13話2色／第6話4色／第15話5色） |

```
  なぜ1柱ずつ出すのか
    0:30〜1:00 は視聴維持率が最も落ちる区間。
    静止画を15秒見せるのは、L3を冒頭から外した理由（上記）と同じ失敗になる。
    語り（約80字 ÷ 5.5字/秒 ＝ 約15秒）に合わせて1柱ずつ現れるなら、
    画面は15秒間動き続ける。
```

### なぜ作り直したか（#57の根拠・**以下は2026年11月21日時点の記録**）

> ⚠ **この節は履歴です。** 下に出てくる色名（空色・杏色・薄紫・朱鷺色・若緑）と
> 濃紺の地は、**#59ですべて置き換わりました**。現行の値は本節の冒頭の表を見てください。

現行配色（`#BBD9F2` ほか6色・和紙の地）を数値で測ったところ、5つの問題がありました。
明度と彩度はOKLCH、コントラスト比はWCAGの式です。

```
  ❶ 6色の明度がほぼ同じ      L* 79.4〜88.9（差9.5）→ 並ぶと一枚の面に見える
  ❷ 彩度がどれも低い          C 0.047〜0.099（平均0.061）→ 強調が効かない
  ❸ 枠線が塗りと見分けられない 枠線/塗り 1.74〜2.58（金が最悪）→ 輪郭がにじむ
  ❹ 帯が背景とほぼ同じ        #F0E9DC 対 #FAF6EF ＝ 比 1.09 → 帯が見えていない
  ❺ 赤枠が弱い                赤枠/塗り 2.33〜3.26（敵対が最悪）
  ＋ 地上(H78)と王統(H92)の色相が14度しか離れていない
```

作り直しでは、**色相を6方向に広く取り直し**（空色255 / 杏色60 / 山吹色88 / 薄紫318 /
朱鷺色25 / 若緑150）、**彩度を上げ**（C 0.075〜0.140）、**明度を色相ごとに作り分け**ました。
隣り合う杏色と山吹色は、明度を 82 対 88・彩度を 0.080 対 0.140 で引き離しています。

3方向（生成り地／紺地／墨地）を実寸で比較し、紺地を採りました。
見本：https://claude.ai/artifact/JiCTLmadrRkBkJnaaet24p

```
             文字/塗り      塗り/地        左右の見え方
  甲 生成り地  5.75〜7.94   2.51〜7.37     つながる
  乙 紺地 ★   7.86〜10.85  8.59〜12.04    分かれる
  丙 墨地      6.48〜8.63   1.67〜2.24     分かれる
```

### 強調枠は墨の「二重の輪」にする（#57の方式・色は#61で変更）

```
   ┌──────────────┐   ← 強調枠 #231815 8px（ノードの外9px）
   │ ┌──────────┐ │   ← すきま 6px（地の色が見える）
   │ │  ノード     │ │
   │ └──────────┘ │
   └──────────────┘

  枠が「塗りの上」ではなく「地の上」に乗るので、塗りの色に関係なく成立する。
  （塗りの縁に枠を描く方式では、濃い塗りのとき枠が消える）
```

**なぜ赤をやめたか（#61）。** 敵対系統が紅 `#D7003A` になり、
赤枠 `#FF4D3D` と**同じ赤系**になったためです。v3当初から
「赤枠と敵対色の色相が近い」は未解決の課題でした（旧 ★印）。墨にすると6色すべてと離れます。

```
  墨 #231815 と6色の明るさの比（大きいほど見分けやすい）
    山吹色 9.56 ／ 菖蒲色 5.35 ／ 緑 6.50 ／ 琥珀色 6.34 ／ 露草色 6.01 ／ 紅 3.26
    最小の紅でも 3.26（WCAGの図形基準 3.0 を満たす）

### 「怪異」と「敵対」を分ける理由（v2から継続）

v2当初は「怪異・敵対」を紫1色にしていました。しかし年表順に近現代まで進むと、
**ヤマタノオロチ（神話の怪物）とGHQ（実在の組織）が同じ色になります**。
これは大原則「1つの見た目に2つの意味を持たせない」（0節）に反するため、分離しました。

```
【v2当初】                     【現在】
 紫 ─┬─ ヤマタノオロチ          菖蒲色   → 神話の怪物のみ
     └─ GHQ          ← 同色     紅 → 実在の対立勢力
```

### 敵対色を適用する基準（全話で一貫させること）

```
① その回の主題において、日本と軍事的・政治的に対立した「側」であること
② 個人に適用するのは、その対立の意思決定者である場合に限る
   （一般の兵士・市民には適用しない）
③ 同じ人物・組織は、どの回でも同じ色にする（回ごとに変えない）
```

### v1から廃止したルール（重要）

| v1のルール | 廃止理由 | 現在の扱い |
|---|---|---|
| 夫婦＝ピンク | 「夫婦」は**関係**であって系統ではない。色は系統専用にする | 夫婦関係は**二重線**（4節）で表す。色は各人の系統に従う |
| カグツチ＝琥珀 | 1キャラ1色では最終話で色が足りない | カグツチは火の神なので**自然・国土・事物（緑）**。彼の重要性は強調枠とサブタイトルで表す |

### サブタイトルも1行しか入らない（2026年11月21日に追加）

   440px の行  超過 0 / 40件
   280px の行  超過 0 / 40件

### ショートは単純な上下半分ではない（重要）

ショートの画面は、**プラットフォームのUIが上下と右側を覆います**。
1080×1920のうち、実際に使えるのは **840 × 1095 px** だけです。

| 覆われる場所 | 幅 | 何が乗るか |
|---|---|---|
| 上部 | 210px | 検索・カメラなどの領域 |
| 下部 | **615px** | タイトル・チャンネル名・登録ボタン・音源情報 |
| 右側 | 240px | 高評価・コメント・共有ボタン |

これはYouTube・Instagram・TikTokの**3媒体すべてのUIを避けた共通の安全領域**です。
TikTokにも転用する方針（#12）のため、この最も厳しい基準を採用します。

```
長尺 1920×1080                    ショート 1080×1920
┌───────────┬───────────┐          ┌─────────────┐ y=0
│           │           │          │░░░ UI 210px ░░░│
│  本編映像  │  相関図    │          ├──────────┬──┤ y=210
│  960×1080 │（L1/L2/L3）│          │  本編映像  │  │
│  x=0〜960 │  960×1080 │          │  840×750  │UI│ ← 右240px
│           │ x=960〜1920│          ├──────────┤  │ y=960
└───────────┴───────────┘          │ 相関図     │  │
                                   │ 840×345   │  │
   本編 : 相関図 ＝ 5 : 5           ├──────────┴──┤ y=1305
   映像が左・相関図が右（#48）       │░░░ UI 615px ░░░│
                                   └─────────────┘ y=1920

                                      本編 : 相関図 ＝ 約 7 : 3
                                      y=1305より下には何も置かない
```

> **v2当初は「相関図は下半分＝1080×960」としていました。** 実測の結果、
> そのうち下615pxはUIに完全に隠れ、実際に見えるのは **840×345px（想定の約28%）**
> であることが判明したため修正しました。

## 6. ショート（9:16）の抜粋ルール

> ## 確定（2026年11月21日・決定#55）
>
> **#50の新しいノード寸法は、ショートの相関図エリア（840×345px）に2行入りません。**
> 決定#28の「最大4ノード（2列×2行）」は成立しないため、**長尺の3寸法をそのまま流用し、
> 1行だけ・最大3個**とします。
>
> ```
>   旧仕様  280×150 を 2行    150×2 ＋ 行間20 ＝ 320 ≦ 345   ✓
>   新寸法  440×170 を 2行    170×2 ＋ 行間20 ＝ 360 > 345   ✗ 15px 超過
>   新寸法  280×210 を 2行    210×2 ＋ 行間20 ＝ 440 > 345   ✗ 95px 超過
>   新寸法  200×210 を 2行    210×2 ＋ 行間20 ＝ 440 > 345   ✗ 95px 超過
> ```
>
> **ショート専用の寸法（400 / 253 / 180px・最大4個）は採りません。**
> 180px幅では神名が3字×2行＝6字しか入らず、**全79ノードのうち16件（20%）がはみ出す**うえ、
> Canvaの共通パーツ集が18点から最大27点に増えます。長尺を流用すればはみ出しは6件で、
> パーツは18点のままです。
> 見本（実寸1080×1920で2案を比較）：https://claude.ai/artifact/XQmgWnCjACYG4fG5eZq5ov

### ショートのノード寸法（長尺と共通）

| 1行に並べる数 | 寸法 | 横の合計 | 840pxとの差 |
|---|---|---|---|
| 1個 | 440 × 170 px | 440px | 余裕400px |
| 2個 | 280 × 210 px | 280×2 ＋ 40 ＝ 600px | 余裕240px |
| 3個 | 200 × 210 px | 200×3 ＋ 40×2 ＝ 680px | 余裕160px |
| 4個 | — | 200×4 ＋ 40×3 ＝ 920px | **80px 超過（不可）** |

**4個必要な場面は、まとめノード1個に畳みます**（例：四兄弟 → 「四兄弟」1個）。

- **そのカットに登場する対象＋直接つながる親または配偶者のみ**を表示する
- **1行だけ**（2行は物理的に入らない）
- ノードは**縮小しない**（神名48pxの根拠が崩れる）。収まらない場合はノードを減らす
- L2・L3はショートでは使わない

例：カグツチ誕生のカット → イザナギ・イザナミ・カグツチ の3ノードのみ

```
  横の検算
    200 × 3 ＋ 余白40 × 2 ＝ 680 ≦ 840  ✓（余裕160px）
    200 × 4 ＋ 余白40 × 3 ＝ 920 > 840  ✗（4個目が右のUI帯に隠れる）
  縦の検算
    210 ≦ 345  ✓（上下に各67pxの余白）
```

## 8. イラストの色調とノードの色は切り離す

**ノードの色＝系統**、**イラストの色調＝その場面の性質**。別物として扱います。

```
   ノードの色  ─→ 系統を示す記号。視聴者が構造を読み取るための情報
   イラスト色調 ─→ 場面の空気。視聴者が感情移入するための演出
                     ↑ 目的が違うので、揃える必要はない
```

| 対象 | ノードの色（系統） | イラストの色調（場面の性質） |
|---|---|---|
| イザナギ・イザナミ | 露草色（天上・主神） | 温かみ・親密さ |
| カグツチ | 緑（自然・国土） | 琥珀〜赤、炎・危うさ |
| ヤマタノオロチ | 紫（怪異） | 暗色・威圧感 |

Midjourneyのプロンプトは**場面の性質**に従って書いてください。

絵柄（線・質感）が全キャラ共通であることは変わりません。
⚠ **画風固定の方法（`--sref` / `--oref`）は課題V（未解決）です。**
決定#19の「`--sref`を使う／`--cref`は誤り」は情報が古く、現在は`--oref`（キャラ参照）と
Edit Modelがあります。**画像生成ツールの選定（課題U）の結果を待って決めること**
（`docs/画像生成ツール比較.md` 8節）。
