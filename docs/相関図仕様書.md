## 0. 見た目の役割（1つの見た目に1つの意味）

1つの見た目に2つの意味を持たせません。この役割分担はシリーズ全体で不変です。

```
  ノードの見た目 ─┬─ 塗りの色    → どの系統に属するか
                  ├─ 赤い枠      → いま注目している対象か
                  ├─ 不透明度    → この場面の中で退場したか
                  ├─ サブタイトル → 状態の正確な説明（死亡・斬殺など）
                  └─ 漢字        → 神名の表記（読ませるためではなく、添えるだけ）

  図の見た目   ──┬─ 帯          → 同じ世代
                  └─ 図を入れ替える → 役目が終わった（＝消す）
```

| 要素 | 意味 | 具体 |
|---|---|---|
| 塗りの色 | 系統（2節） | 6系統の固定色 |
| 赤枠 `#E03131` / 6px | いま注目している対象 | L1では「本編映像に映っているカット中」、紹介カット・L3では「今回の話の範囲」 |
| 不透明度50% | **その場面の中で起きた退場**（死亡・追放・退けられた等） | 塗りの色は変えない |
| サブタイトル | 状態の正確な説明 | 「死亡（カグツチ出産）」「正式な子に数えられず」 |
| 漢字（小さい文字） | 神名の表記（#51） | スマホでは読めない前提。読ませるのは紹介カットの役目 |
| 帯 `#F0E9DC` | 同じ世代（#52） | ラベルは「主役から見た関係」（#53） |

### 「消す」と「不透明度50%」の使い分け（#49）

**この2つは別の意味なので、混ぜないこと。**

```
  不透明度50%  ＝ いま見せている場面の中で、退場が起きた
                   例）カット13でイザナミが死ぬ
                       → イザナミを50%に落とし「死亡（カグツチ出産）」と書く
                       （ここで消すと、死んだこと自体が画面から伝わらない）

  消す          ＝ 次の場面に進むとき、その場面に要らないノードを外す
                   例）カット12でカグツチが生まれる図には、
                       ヒルコ・アワシマ・大八島国はもう出さない
```

**50%のまま次の場面へ持ち越すのは、その退場がまだ話の中心にある場合だけです。**
中心から外れたら消します。50%は「永久にそこに残る印」ではありません。

> **なぜ消すのか**：全15話の台本から実測すると、消さない場合の同時表示は最大12個に達し、
> 読める量を超えます。消す運用なら**最大6個・平均3.9個**に収まります（#49）。

## 1. 相関図は4層構造（シリーズ全体の骨格）

79ノード・16段を1枚に収めることは不可能なため、役割の違う4種類の図を使い分けます。

| 層 | 名称 | 用途 | 表示タイミング | ノード数 |
|---|---|---|---|---|
| **L0** | **登場人物紹介カット** | 「今日の物語に登場する神々」 | **冒頭 0:30 に 約15秒**（全画面） | **10前後**（横4個・最大3段） |
| **L1** | シーン図 | 本編中つねに表示するメインの相関図 | 常時（**画面の右半分**） | **上限なし。同時最大6個・平均3.9個** |
| **L2** | 章図 | 章（3〜4話）のまとめ | 章の最終話の末尾（全画面） | 最大20 |
| **L3** | 全体系譜図 | 「今日の話は全体のここでした」 | **まとめパート（9:00台）**（全画面） | 約20（畳んだ後）・表示9行 |

> ⚠ **全15話のノードの実測は `docs/L1ノード一覧.md`（2026年11月15日）を参照。**
> 累計ノード数は**66ではなく79**です（`docs/シリーズ構成シミュレーション.md` 2節の66は
> 企画段階の見積もりで、台本と合っていません。L3の設計は79件の台帳から始めること）。

### L3を冒頭からまとめへ移した理由（v2から継続）

v2当初はL3を「各話冒頭に約3秒」としていましたが、**0:20〜0:60は視聴維持率が最も
急に落ちる区間**です。そこに約20ノードの静止図を3秒置くと、視聴者は「3秒では読み切れない
情報量」を前に理解を諦め、離脱の引き金になります。

また「今日の話は全体のどこか」は、**見終わった人にしか意味がありません**。

### L0は「登場人物紹介カット」に作り替えた（#54）

v2のL0は「最大3ノード・1.5秒」でした。これを**約15秒の紹介カット**に差し替えます。

| 項目 | 旧L0（v2） | 登場人物紹介カット（v3） |
|---|---|---|
| 表示 | 全画面 1920×1080 | 全画面 1920×1080（変更なし） |
| 長さ | 1.5秒 | **約15秒** |
| ノード数 | 最大3 | **10前後**（横4個・帯で世代に分ける） |
| ノード規格 | 440 × 100 px | **440 × 180 px**／神名48px・漢字32px |
| 見せ方 | 静止画を1.5秒 | **語りに合わせて1柱ずつ現れる** |
| 文字 | なし | タイトル「今日の物語に登場する神々」＋副題「色は、その神の立ち位置を表しています」 |
| 色の凡例 | なし | **その話で実際に使う色だけ**（第13話2色／第6話4色／第15話5色） |

```
  なぜ1柱ずつ出すのか
    0:30〜1:00 は視聴維持率が最も落ちる区間。
    静止画を15秒見せるのは、L3を冒頭から外した理由（上記）と同じ失敗になる。
    語り（約80字 ÷ 5.5字/秒 ＝ 約15秒）に合わせて1柱ずつ現れるなら、
    画面は15秒間動き続ける。
```

## 2. 配色（色＝系統／全時代共通・6系統）

色は**系統**だけを表します。個別キャラに色を割り当てることは禁止です
（v1の「カグツチ＝琥珀」は、最終話で色が足りなくなるため**廃止**）。

年表順に近現代まで進むため、**神話だけでなく全時代で使える6系統**とします。

| 系統 | 神話での例 | 日本史・近現代での例 | 塗り | 枠線 | 文字 |
|---|---|---|---|---|---|
| 天上・主神 | 天津神（イザナギ、アマテラス、ニニギ） | 朝廷・中央権力 | `#BBD9F2` 空 | `#4A87C4` | `#14304F` |
| 地上・土着 | 国津神（オオクニヌシ、出雲の神々） | 地方勢力・豪族 | `#E0C9A6` 土 | `#A8813F` | `#46330F` |
| 人間・王統 | 神武以降の天皇 | 実在の人物 | `#F2D98D` 金 | `#C9A227` | `#4A3708` |
| **怪異** | ヤマタノオロチ、黄泉醜女 | — （**神話の存在にのみ使う**） | `#D4C2E8` 紫 | `#8E6BBF` | `#33204F` |
| **敵対** | ナガスネヒコ | 対立した国家・組織・人物 | `#DCB0A8` 赤褐 | `#A85A4A` | `#4A201A` |
| 自然・国土・事物 | 大八島国、自然の神々、カグツチ、草薙剣 | 地名、法令、指令、事物 | `#C6E3C0` 緑 | `#6BA85F` | `#23401E` |

背景：`#FAF6EF`（和紙色）、エリア外枠 `#D8CFC0`。

> ⚠ **課題AH（未解決）：「人間・王統（金）」は神話15話で出番がありません。**
> 第15話カット15でイワレビコは「初代天皇として即位」しますが、台本はサブタイトルだけを
> 差し替えて塗りは空色のままです。①そのまま空色（金はシリーズ2以降で初出）
> ②即位で金に変える、のどちらかを決める必要があります。
> **②は1話の途中で色が変わるのが視聴者に伝わるか未検証。**
> 縄文・日本史で必ず使うので、仕様から消す必要はありません。根拠は `docs/L1ノード一覧.md` 6節。

### 「怪異」と「敵対」を分ける理由

v2当初は「怪異・敵対」を紫1色にしていました。しかし年表順に近現代まで進むと、
**ヤマタノオロチ（神話の怪物）とGHQ（実在の組織）が同じ色になります**。
これは大原則「1つの見た目に2つの意味を持たせない」（0節）に反するため、分離しました。

```
【v2当初】                     【現在】
 紫 ─┬─ ヤマタノオロチ          紫   → 神話の怪物のみ
     └─ GHQ          ← 同色     赤褐 → 実在の対立勢力
```

### 敵対色を適用する基準（全話で一貫させること）

```
① その回の主題において、日本と軍事的・政治的に対立した「側」であること
② 個人に適用するのは、その対立の意思決定者である場合に限る
   （一般の兵士・市民には適用しない）
③ 同じ人物・組織は、どの回でも同じ色にする（回ごとに変えない）
```

> **実装時に要確認**：赤褐色 `#DCB0A8` の塗りに、赤枠ハイライト `#E03131` が
> 重なったときに見分けがつくか、**スマホの実機で確認すること**。
> 帯 `#F0E9DC` を入れると画面内の暖色が3つになるため、あわせて確認する。

### v1から廃止したルール（重要）

| v1のルール | 廃止理由 | v2以降の扱い |
|---|---|---|
| 夫婦＝ピンク | 「夫婦」は**関係**であって系統ではない。色は系統専用にする | 夫婦関係は**二重線**（4節）で表す。色は各人の系統に従う |
| カグツチ＝琥珀 | 1キャラ1色では最終話で色が足りない | カグツチは火の神なので**自然・国土・事物（緑）**。彼の重要性は赤枠とサブタイトルで表す |

## 3. ノードの規格

### L1は「行に並べる数」で幅が変わる（#50）

```
            920 − 40 × (n − 1)
    幅 ＝ ──────────────────      n ＝ その行に並べる数
                    n

    920px ＝ 相関図エリア 960px − 外周 20px × 2
     40px ＝ ノード間の余白
```

| n | 幅 | 高さ | 神名 | 1行の字数 | 行数 | 漢字 | サブタイトル |
|---|---|---|---|---|---|---|---|
| 1 | **440px**（中央寄せ） | 170px | 48px | 9字 | 1行 | 32px | 28px |
| 2 | **440px** | 170px | 48px | 9字 | 1行 | 32px | 28px |
| 3 | **280px** | 210px | 48px | 5字 | **2行** | 24px | 26px |
| 4 | **200px** | 210px | 48px | 4字 | **2行** | 22px | 24px |
| 5 | 152px | — | — | 3字 | — | — | **使用禁止** |

**縦横比は固定しません。** 親の段は440px・横長、兄弟の段は280pxまたは200px・縦長になります。
**1個だけの行は440pxにして、幹（x=1440）の真下に中央寄せします**（起点 x=1220）。

| 神名 1行目 | 上端から60px | 56px | 56px | 62px |
| 神名 2行目 | （1行のみ） | 104px | 104px | （1行のみ） |
| 神名が1行のとき | 60px | 80px | 80px | 62px |

L2・L3が12px。枠線は3px（系統の枠線色）、赤枠は6px `#E03131`。

### 神名が入るかの実測（全79ノード・2026年11月21日）

```
  48px の文字は 1字 ＝ 48px。入る字数 ＝ 幅 ÷ 48

   440px  9字   1行    はみ出し  3 / 79件
   280px  5字 × 2行    はみ出し  1 / 79件
   200px  4字 × 2行    はみ出し  6 / 79件
   ────────────────────────────────────
   旧仕様（280px・1行のみ）        30 / 79件（38%）  ← これが#50の理由
```

| 幅 | はみ出す神名 |
|---|---|
| 440px（3件） | 八塩折の酒・八つの門／生大刀・生弓矢・天詔琴／天之御舎（出雲大社） |
| 280px（1件） | 生大刀・生弓矢・天詔琴 |
| 200px（6件） | 上記3件＋八咫鏡・八尺瓊勾玉／多邇具久・久延毘古／コノハナサクヤヒメ |

> **440pxでもはみ出す3件は、ノード名そのものを改める必要があります**（作業③）。
> いずれもまとめノードなので、中身を削らずに短い名前へ置き換えられます。
> **神名48pxはスマホ縦で9.7pt相当で、これが読める下限です（決定#6）。縮小は禁止。**
>
> ⚠ **決定#50の本文にある「29個（37%）」は誤りです。** 2026年11月21日に全79件を
> 数え直した結果は **30件（38%）**（6字以上の神名が30件ある）。v3はこの数値を使います。

### サブタイトルも1行しか入らない（2026年11月21日に追加）

**サブタイトルは1行だけです。** ノードの高さに2行ぶんの余地がありません
（440×170ならサブタイトルのベースラインが142pxで、下端まで28pxしか残らない）。

```
  入る字数 ＝ 幅 ÷ サブタイトルの文字サイズ

   440px ÷ 28px = 15字
   280px ÷ 26px = 10字
   200px ÷ 24px =  8字

  全15話の台本にある「サブタイトル」の指定40件を実測した結果
   440px の行  超過 0 / 40件
   280px の行  超過 0 / 40件
   200px の行  超過 4 / 40件
     正式な子に数えられず(10)／先に降りていた天つ神(10)／
     八つの頭と八つの尾(9)／オオヤマツミの長女(9)
```

**4個並べる行（200px）に置くノードは、サブタイトルを8字以内にすること。**
入らない場合は、その行を3個以下に減らします（幅が280pxになり10字入る）。

## 5. キャンバスサイズ

| 用途 | サイズ | 根拠 |
|---|---|---|
| 長尺（16:9）の相関図エリア | **960 × 1080 px** | 動画1920×1080pxの**右半分**（x = 960〜1920・#48） |
| ショート（9:16）の相関図エリア | **840 × 345 px** | UIに覆われない領域の実測値（下記） |

### ショートは単純な上下半分ではない（重要）

ショートの画面は、**プラットフォームのUIが上下と右側を覆います**。
1080×1920のうち、実際に使えるのは **840 × 1095 px** だけです。

| 覆われる場所 | 幅 | 何が乗るか |
|---|---|---|
| 上部 | 210px | 検索・カメラなどの領域 |
| 下部 | **615px** | タイトル・チャンネル名・登録ボタン・音源情報 |
| 右側 | 240px | 高評価・コメント・共有ボタン |

これはYouTube・Instagram・TikTokの**3媒体すべてのUIを避けた共通の安全領域**です。
TikTokにも転用する方針（#12）のため、この最も厳しい基準を採用します。

```
長尺 1920×1080                    ショート 1080×1920
┌───────────┬───────────┐          ┌─────────────┐ y=0
│           │           │          │░░░ UI 210px ░░░│
│  本編映像  │  相関図    │          ├──────────┬──┤ y=210
│  960×1080 │（L1/L2/L3）│          │  本編映像  │  │
│  x=0〜960 │  960×1080 │          │  840×750  │UI│ ← 右240px
│           │ x=960〜1920│          ├──────────┤  │ y=960
└───────────┴───────────┘          │ 相関図     │  │
                                   │ 840×345   │  │
   本編 : 相関図 ＝ 5 : 5           ├──────────┴──┤ y=1305
   映像が左・相関図が右（#48）       │░░░ UI 615px ░░░│
                                   └─────────────┘ y=1920

                                      本編 : 相関図 ＝ 約 7 : 3
                                      y=1305より下には何も置かない
```

> **v2当初は「相関図は下半分＝1080×960」としていました。** 実測の結果、
> そのうち下615pxはUIに完全に隠れ、実際に見えるのは **840×345px（想定の約28%）**
> であることが判明したため修正しました。

## 8. イラストの色調とノードの色は切り離す

**ノードの色＝系統**、**イラストの色調＝その場面の性質**。別物として扱います。

```
   ノードの色  ─→ 系統を示す記号。視聴者が構造を読み取るための情報
   イラスト色調 ─→ 場面の空気。視聴者が感情移入するための演出
                     ↑ 目的が違うので、揃える必要はない
```

| 対象 | ノードの色（系統） | イラストの色調（場面の性質） |
|---|---|---|
| イザナギ・イザナミ | 空色（天上・主神） | 温かみ・親密さ |
| カグツチ | 緑（自然・国土） | 琥珀〜赤、炎・危うさ |
| ヤマタノオロチ | 紫（怪異） | 暗色・威圧感 |

Midjourneyのプロンプトは**場面の性質**に従って書いてください。

絵柄（線・質感）が全キャラ共通であることは変わりません。
⚠ **画風固定の方法（`--sref` / `--oref`）は課題V（未解決）です。**
決定#19の「`--sref`を使う／`--cref`は誤り」は情報が古く、現在は`--oref`（キャラ参照）と
Edit Modelがあります。**画像生成ツールの選定（課題U）の結果を待って決めること**
（`docs/画像生成ツール比較.md` 8節）。
服装の方針は `docs/絵柄仕様.md`（決定#39・帯の色を系統色に合わせる）を参照。
