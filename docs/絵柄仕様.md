# 絵柄仕様

最終更新：2026年11月13日

**本書は絵柄（画風・服装・一貫性の保ち方）の唯一の正。**
個々の神の見た目は `docs/キャラ設定表.md`。相関図のデザインは `docs/相関図仕様書.md`。
仕様が食い違ったら `docs/決定ログ.md` を優先。

## 0. この文書が解く問題

```
  全15話で、新規の絵が必要なカットは 246枚
  ┌────────────────────────────────┐
  │ 同じ神が、話をまたいで何度も出てくる         │
  │   アマテラス   第3・4・5・11・15話  5話      │
  │   スサノオ     第3・4・5・6・8話    5話      │
  │   オオクニヌシ 第7・8・9・10話      4話      │
  │                                          │
  │ 顔が変わると「別人が出てきた」と見える       │
  │ ＝ チャンネルの信頼性が最初に壊れる箇所      │
  └────────────────────────────────┘
```

この文書は **①画風を揃える ②服装を揃える ③顔を揃える** の3つを定める。

## 1. 画風の共通定義（246枚すべてに適用）

競合調査で「ジブリらしさ」を5つの構成要素に分解した（`docs/競合調査.md` 4節）。
**その5要素をそのまま指定する。** 特定の作品名に依存しない。

| 狙う印象 | 構成要素 | 英語の指定句 |
|---|---|---|
| やわらかい | 影が少なく平坦な塗り | `flat cel shading, minimal gradients` |
| 落ち着く | 彩度が中〜低め・原色を使わない | `muted low-saturation palette, no primary colors` |
| 自然 | 表情を誇張しない | `calm unexaggerated expression, eyes not widened` |
| 丁寧 | 輪郭線の太さが均一 | `thin uniform clean line art` |
| 余白がある | 背景が淡く単純 | `simple pale background, ample negative space` |

### 共通画風句（すべてのプロンプトの先頭に置く）

```
cel-shaded anime illustration, flat cel shading, minimal gradients,
thin uniform clean line art, muted low-saturation earth palette,
calm unexaggerated expression, simple pale background,
ample negative space, soft diffused daylight, no text
```

**`no text` を必ず入れる。** 生成画像に文字が入ると、相関図の文字と混線する。

## 2. 禁止事項

| 禁止 | 理由 |
|---|---|
| プロンプトに `Studio Ghibli` `Miyazaki` などの作品名・作家名 | サービス規約で制限される場合がある。公表後の心証も悪い |
| 他人の著作物を参照画像に指定する（ジブリ作品・競合チャンネルの画像） | 他人の著作物に直接依存することになる |
| 実在の神社の写真・神社を思わせる生成画像 | 実在の神社と誤認させる。`docs/場所と神社パート仕様.md` |
| 彩度を上げて煽る絵（高コントラスト・発光・叫び顔） | 競合Bの路線。本チャンネルは「煽らない」が方針 |

**参照画像は、自分で生成した1枚に固定する**（決定#19）。

## 3. 服装の方針：系統で描き分ける（丙案・2026年11月13日決定）

### 決定の経緯

```
  当初の想定「記紀に容姿の記述はない＝服装は創作」
        ↓
  一次資料を確認 → 装いの記述が複数あった（5節）
        ↓
  3案を比較（甲 出土品どおり／乙 神職装束風／丙 系統で描き分け）
        ↓
  丙案を採用
```

**乙案（神職装束風）を外した理由：出典を示せないこと。**
いまの神職装束は平安期の装束を基礎にし、細部は後世に整えられたもので、
神話の時代から千年以上あとの姿になる。「比定地は伝承地と明示する」という
既存の方針（決定#38）と噛み合わない。加えて競合2チャンネルが同じ路線で、
差別化もできない。

### 丙案の内容

```
  土台（全員共通）                       系統ごとの差
  ┌──────────────────┐      ┌──────────────────┐
  │ 麻の衣（筒袖または貫頭衣）  │      │ 布の色    白 ←→ 生成り・土色 │
  │ 男はみづら、女は結い上げ    │  ＋  │ 勾玉の量  連ねる ←→ 一つ     │
  │ 勾玉・管玉の飾り           │      │ 帯の色    相関図の系統色     │
  └──────────────────┘      └──────────────────┘
```

**帯の色を相関図の系統色に合わせる。** ノードの塗りと絵が同じ意味を指すので、
見た目が意味を二重に補強する（意味の混線ではない。同じ意味を2箇所で言う）。

### 系統別の装い規則

| 系統 | 布 | 帯の色 | 勾玉 | 履物 | 備考 |
|---|---|---|---|---|---|
| 天上・主神 | **晒した白の麻** | 空色 `#BBD9F2` | **連ねる**（御統） | あり | 古事記のアマテラスに準拠 |
| 地上・土着 | 生成りの麻 | 土色 `#E0C9A6` | **一つ** | 素足も可 | 素朴さで天津神と差をつける |
| 人間・王統 | 麻に絹を混ぜる | 金 `#F2D98D` | 中量＋金の腕輪 | あり | 第15話末の即位以降・次シリーズ用 |
| 怪異 | 衣を着ない／灰白の布 | なし | なし | 素足 | 人型でない場合は体そのもの |
| 敵対 | 麻＋革の挂甲（けいこう） | 赤褐 `#DCB0A8` | なし | あり | 挂甲は人物埴輪に拠る |
| 自然・国土・事物 | — | — | — | — | 動物・島・事物。**人型にしない** |

⚠ **新しい未検証事項**：敵対系統の帯 `#DCB0A8` が画面に入ると、赤系が
「赤褐の帯・赤褐のノード・赤枠 `#E03131`」の3つになる。
領域が違う（絵の中／相関図の中）ので混線しにくいはずだが、**実機で確認すること。**

## 4. 一貫性を保つ仕組み

### 基準画像（アンカー）方式

```
  ① キャラごとに「基準画像」を1枚つくる
       正面・バストアップ・無表情・共通画風句のみ
       納得いくまで作り直す。ここで妥協すると全話に響く
          ↓
  ② 以降すべてのカットは、基準画像を参照して生成する
          ↓
  ③ 基準画像は差し替えない
       差し替えると、それ以前に作った絵と顔が合わなくなる
```

### 基準画像の置き場所

```
  episodes/_anchors/
    05_アマテラス_基準.png        ← 番号は キャラ設定表の通し番号
    05_アマテラス_基準_プロンプト.txt  ← 生成に使った句をそのまま保存
```

**プロンプトを必ず一緒に保存する。** 作り直しが必要になったとき、
同じ句から始められないと再現できない。

### ツール別の参照機能（★ツール未決定のため空欄あり）

| ツール | 参照機能 | 記法 | 状態 |
|---|---|---|---|
| Midjourney | スタイル参照 | `--sref <URL>` | 画風は得意、顔は△との評価（課題U） |
| Leonardo.Ai | キャラクター参照 | 要確認 | **未確認** |
| Adobe Firefly | 要確認 | 要確認 | **未確認** |
| 参照画像編集系 | 画像を直接入力 | 要確認 | **未確認** |

**ツールが決まるまで、この表は埋まらない。**
`docs/画像生成ツール比較.md` と課題U・Vを参照。

## 5. 服装の典拠（一次資料で確認済み）

| 出典 | 原文 | 読み取れること |
|---|---|---|
| 古事記・黄泉 | 「左の御髻に刺させる湯津爪櫛の男柱一箇取り闕きて」 | **イザナギはみづらに結い、櫛を刺している** |
| 古事記・誓約 | 「御髪を解きて、御髻に纏かして」 | **アマテラスは髪を解き、みづらに結い直す**（本来は男性の髪型・武装の描写） |
| 古事記・誓約 | 「八尺の勾璁の五百津の御統の珠を纏き持たして」 | 勾玉を連ねた飾りを、左右のみづら・鬘・両手に着ける。**一粒ではなく大量** |
| 古事記・誓約 | 「背には千入の靫を負ひ」「臂には稜威の高鞆を取り佩ばして」 | 矢筒を背と胸に、腕に鞆（弓の弦が当たる革の当て）。**神は武装する** |
| 古事記・天岩戸 | 「天の日影を手次に繋けて、天の真拆を鬘として」「小竹葉を手草に結ひて」 | ウズメは蔓植物をたすきと髪飾りにし、笹の葉を手に持つ。**植物が衣装の一部** |
| 魏志倭人伝 | 「婦人被髮屈紒、作衣如單被、穿其中央、貫頭衣之」 | 3世紀の倭。女性は髪を結い、一枚布の中央に穴をあけて頭を通す（貫頭衣） |
| 魏志倭人伝 | 「男子皆露紒、以木緜招頭」「其衣横幅、但結束相連、略無縫」 | 男子は髪を露わに結い、布を結び合わせ、ほとんど縫わない |
| 人物埴輪 | （東京国立博物館の解説） | 飾りのついた帽子・みづら・首飾りが高い身分の表現。挂甲の武人も出土 |

**確認の経路**：古事記は原文テキスト（Wikibooks版）、倭人伝は三國志 卷30（中文ウィキソース）。
いずれも2026年11月13日に確認。

⚠ **刊本での再確認が必要。** ウィキ系のテキストは翻刻であり、校訂された刊本
（岩波文庫・新潮日本古典集成など）ではない。**公開前に刊本で突き合わせること。**
