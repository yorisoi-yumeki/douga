## 2. A「アニメ神話劇場」の中身

> 神話をアニメで見せるチャンネルです。いまは古事記を、はじめから順に。前編を公開中。
> 後編は制作中です。登録しておくと、次の演目が出たときにお知らせが届きます。

短い。主張も理念も書かない。**「何を見せるか」だけ。**

### 概要欄の構成（ユーザーが「裏付けがある」と感じた根拠）

```
  ① 1段落のあらすじ
  ② 目次（7章）     00:00 序 / 00:54 天地開闢 / 11:19 黄泉の国 /

  ④ ▼参考文献  ← ★ここ
  ⑤ ハッシュタグ12個
```

**参考文献として4点を明記している。**

| 文献 | 種別 |

| 竹田恒泰『現代語古事記』 | 一般書 |

## 4. 絵柄の比較

### A アニメ神話劇場 ＝ 静・淡・余白

```
┌────────────────────────────┐
│ アニメで見る          ┌──────┐  │  ・背景は淡い水色、ほぼ無地
│                      │人物の  │  │  ・人物はバストアップ、穏やかな表情
│  古 事 記            │アップ  │  │  ・輪郭線は均一で細め
│  （黒の毛筆体）        │        │  │  ・影が少なく平坦（セル画調）
│   前編               └──────┘  │  ・中彩度。煽らない
└────────────────────────────┘
   文字は絵に重ねず、左の余白に置く
   文字数：6＋3＋2
```

### B アニメで語り継ぐ日本の物語 ＝ 動・濃・全面

```
┌────────────────────────────┐
│ [ロゴ]      絵が全面           │  ・高彩度、発光（赤い目など）
│                              │  ・顔のアップ・叫び／または夕日の情景
│  ■ 伝説の大蛇退治 ■          │  ・白〜金グラデのゴシック体を絵に重ねる
│      ― ヤマタノオロチ ―       │  ・煽る
└────────────────────────────┘
   文字数：7〜8文字の1行＋サブタイトル
   （実例：伝説の大蛇退治7／日本のはじまり7／闇を破った笑い声8）
```

**Bは場面で2段階を使い分けている。** 穏やかな回は暖色のやわらかい絵、
戦い・怪異の回は高コントラストの劇画調。

### 「ジブリのテイスト」の正体

Aを見て感じる「ジブリらしさ」は、以下の要素の組み合わせである。
**スタジオジブリ特有の表現ではなく、セル画調アニメの一般的な特徴に近い。**

| 感じる印象 | 実際の構成要素 |
|---|---|
| やわらかい | 影が少なく平坦な塗り（フラットなセルシェーディング） |
| 落ち着く | 彩度が中〜低め。原色を使わない |
| 自然 | 表情が誇張されていない（叫ばない・目を見開かない） |
| 丁寧 | 輪郭線の太さが均一。線が揺れない |
| 余白がある | 背景が淡く単純。情報量が少ない |

**この分解が重要。** Midjourneyのプロンプトに「Ghibli」と書いても、この5要素は
再現されない（かつ規約・心証の両面で避けるべき。5節）。要素で指定すること。

## 5. 絵柄を参考にする際の注意（著作権）

| 項目 | 判断 |
|---|---|
| 画風そのものを似せること | 著作権の保護対象外（アイデアと表現の二分法）。**違法ではない** |
| プロンプトに「Studio Ghibli」「宮崎駿」と書く | **やらない**。生成AIサービスの規約で制限される場合があり、公表後の心証も悪い |
| ジブリ作品の画像を `--sref` に指定する | **やらない**。他人の著作物を直接参照させることになる |
| 競合チャンネルの画像を `--sref` に指定する | **やらない**。同上 |
| 構成要素（平坦な塗り・細い均一線・低彩度）で指定する | **これをやる**。特定の作品に依存しない |

**`--sref` の参照元は、自分で生成した1枚に固定する**（決定#19）。
自作であれば全話で画風が揃い、かつ他人の著作物に依存しない。

## 6. この調査で分かったこと

### 良い知らせ

| 事実 | 意味 |
|---|---|
| Aが1本で70.2万再生・2.71万登録 | **「日本神話アニメ」には需要がある。** 引き継ぎ書の前提（日本史解説は飽和）は神話分野に当てはまらない |
| Aが参考文献4点を概要欄に明記して伸びている | **出典を出すことは視聴数の妨げにならない。** 決定#24の裏付け |
| 相関図を常時表示する構成は、A・Bとも確認できていない | **差別化の余地はまだ空いている可能性がある**（未確認。6節の確認事項1） |

### 悪い知らせ

| 事実 | 意味 |
|---|---|
| B が本チャンネルの1本目（ヤマタノオロチ）を10月23日に公開済み | **1本目（#15・#22で確定）が真正面からぶつかる** |
| Bは目的・典拠・公開順・日本書紀の扱いまで本チャンネルとほぼ一致 | 後発として「なぜこちらを見るのか」の答えが相関図しかない |
| Aは1本44分、Bは週2.5本 | 本数でも尺でも追えない（本チャンネルは週13時間・週1本・10分想定） |
| 44分1本が20分×4本を再生数で2.5倍上回った | **分割するほど有利とは限らない。** ただしA は1本のみの事例であり、断定はできない |

### 制作手法についての推測（未確認）

AもBも、この本数と尺を短期間で出している。手描きアニメでは成立しにくいため
AI生成を多用していると**推測される**。本編を見ていないため確認できていない。
**断定しないこと。**
