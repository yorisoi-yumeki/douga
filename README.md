## シリーズ範囲

日本神話は **全15話（国産み・神生み 〜 神武東征）** で完結。古事記準拠。

**物語の順番と、公開する順番は別です。**

```
物語の順番（再生リストで担保）    公開する順番
  1. 国産み・神生み                 1本目      ヤマタノオロチ退治
  2. 黄泉の国                       2本目〜    未定
  …                                  …
  6. ヤマタノオロチ退治             5本目前後  国産み・神生み
```

1本目をヤマタノオロチにする理由は、①検索需要が桁違いに大きい ②原典絵が豊富で
Midjourney依存が減り工数が最小 ③1話完結で前提知識が要らない、の3点
（`docs/外部レビュー結果.md` 参照）。

## 制作ルール（要点）

- **ファクトチェック**：すべての事実は2つ以上の出典でクロスチェックする。
- **イラスト**：パブリックドメインの原典絵を優先。他クリエイターのキャラデザ模倣は禁止。
  原典絵がない神はMidjourney（**`--sref`**で画風統一）で新規作成する。
- **相関図の見た目は4つの役割に分ける**（1つの見た目に2つの意味を持たせない）：
  - 塗りの色 → 系統（6系統・全時代共通。「怪異」＝神話の怪物と「敵対」＝実在の対立勢力は別の色）
  - 赤枠 → いま注目している対象
  - 不透明度50% → 退場（死亡など）
  - サブタイトル → 状態の正確な説明
- **相関図は3層構造**：L1シーン図（常時・最大8ノード）／L2章図（章末）／L3全体系譜図（各話冒頭3秒）

詳細は `docs/引き継ぎ書_歴史神話YouTubeチャンネル.md` を参照。
