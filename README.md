# 歴史・神話解説YouTubeチャンネル

日本神話・ギリシャ神話・日本史・世界史の解説動画チャンネルの制作リポジトリ。
差別化ポイントは「画面の半分を人物相関図・年表エリアにする」構成。

- 長尺（16:9）：左右分割（本編｜相関図）
- ショート（9:16）：上下分割（本編／相関図の抜粋）

## フォルダ構成

```
douga/
├── README.md                        … このファイル
├── docs/                            … 企画・仕様・ルール
│   ├── 引き継ぎ書_歴史神話YouTubeチャンネル.md  … 企画検討の記録（原本）
│   ├── シリーズ構成シミュレーション.md          … 全15話の構成・段数・ノード数の算出
│   └── 相関図仕様書.md                        … ★相関図デザインの唯一の正（v2）
└── episodes/                        … 話数ごとの制作物
    └── 01_国産み神生み/
        └── 01_国産み神生み_台本.md
```

**仕様が食い違ったときは `docs/相関図仕様書.md`（v2）を優先します。**
引き継ぎ書は企画検討の記録であり、相関図の配色部分はv2で作り直されています。

## シリーズ範囲

日本神話は **全15話（第1話 国産み・神生み 〜 第15話 神武東征）** で完結。古事記準拠。

## 制作ルール（要点）

- **ファクトチェック**：すべての事実は2つ以上の出典でクロスチェックする。
- **イラスト**：パブリックドメインの原典絵を優先。他クリエイターのキャラデザ模倣は禁止。
  原典絵がない神はMidjourney（`--cref`で絵柄統一）で新規作成する。
- **相関図の見た目は4つの役割に分ける**（1つの見た目に2つの意味を持たせない）：
  - 塗りの色 → 系統（5系統・チャンネル全体共通）
  - 赤枠 → いま注目している対象
  - 不透明度50% → 退場（死亡など）
  - サブタイトル → 状態の正確な説明
- **相関図は3層構造**：L1シーン図（常時・最大8ノード）／L2章図（章末）／L3全体系譜図（各話冒頭3秒）

詳細は `docs/引き継ぎ書_歴史神話YouTubeチャンネル.md` を参照。
