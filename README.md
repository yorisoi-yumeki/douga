# 歴史・神話解説YouTubeチャンネル

日本神話・ギリシャ神話・日本史・世界史の解説動画チャンネルの制作リポジトリ。
差別化ポイントは「画面の半分を人物相関図・年表エリアにする」構成。

- 長尺（16:9）：左右分割（本編｜相関図）
- ショート（9:16）：上下分割（本編／相関図の抜粋）

## フォルダ構成

```
douga/
├── README.md                        … このファイル
├── docs/                            … 企画・仕様・ルール

└── episodes/                        … 話数ごとの制作物
    └── 01_国産み神生み/
        └── 01_国産み神生み_台本.md
```

## 制作ルール（要点）

- **ファクトチェック**：すべての事実は2つ以上の出典でクロスチェックする。
- **イラスト**：パブリックドメインの原典絵を優先。他クリエイターのキャラデザ模倣は禁止。
  原典絵がない神はMidjourney（`--cref`で絵柄統一）で新規作成する。
- **相関図の色**：色＝カテゴリ、赤枠＝ハイライト。意味を混同しない。

詳細は `docs/引き継ぎ書_歴史神話YouTubeチャンネル.md` を参照。
